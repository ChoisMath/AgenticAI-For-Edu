# case-based-problem skill

학생을 의사결정자의 자리에 세우는 사례 기반 문제와 상황 제시문을 생성한다.

## 핵심 원칙

이 skill은 다음 한 가지 전제 위에 만들어졌다.

> 자료가 풍부해도 그것이 학생 자신의 문제로 다가오지 않으면 학습은 외따로 남는다.

학생이 사례 속 인물의 자리에 앉아 자기 가치관으로 결정을 내릴 때, 학습은 자기 사건이 된다. 그 자리를 만드는 것이 사례 기반 문제다.

상황학습(situated learning) 이론은 학습이 추상적 지식의 전달이 아니라 구체적 맥락 속에서 일어난다고 본다. 유욱희·오영열(2014)은 상황학습 기반 수업이 학생의 학업성취도와 수학적 태도 모두에 긍정적 영향을 미쳤음을 실증적으로 보고했다. 추상에서 구체로 학습을 옮긴 결과는 단순한 동기 부여 수준이 아니라 학습의 성격 자체를 바꾼 셈이다. 이 skill의 모든 결정은 그 변화의 기제 위에 서 있다.

## 핵심 메시지

> 사례는 학생의 답을 미리 정해 두지 않는다.

교사가 사례를 만들 때 가장 흔히 빠지는 함정은 '의도한 정답을 숨겨 두는 것'이다. "B가 답이지"라는 마음으로 사례를 만들면, A를 선택한 학생은 자연스레 '틀린 학생'이 된다. 좋은 사례는 그런 정답을 두지 않는다. 답은 학생의 가치관에 달려 있고, 학생의 가치관에 답이 달려 있다는 사실 자체가 학생을 의사결정자의 자리로 데려간다.

이 skill은 그 자세를 작가의 자리부터 비평가의 자리까지 일관되게 유지한다.

## 두 가지 작업 모드 — 사례 기반 문제 vs 상황 제시문

이 skill은 두 가지 결과물을 만들 수 있다. 자매 관계지만 역할이 다르다.

| 구분 | 사례 기반 문제 | 상황 제시문 |
|---|---|---|
| **성격** | 의사결정 과제 | 탐구의 진입점 |
| **질문의 끝** | 있음 ("당신이라면 어떻게?") | 없음 (학생이 변수를 정의) |
| **단원 위치** | 중반·끝 (배운 것을 통합) | 시작 (학생을 끌어들임) |
| **분량** | A4 반 페이지 이내 | 한 단락 + 시작 질문 |
| **학생의 역할** | 결정 내리기 | 변수 정하고 탐구 시작 |
| **예시** | "23세 정수가 두 적금 상품 사이에서…" | "확진자가 일주일 만에 100→800. 계속되면?" |

교사가 입력에서 어떤 모드를 원하는지 명시하지 않으면, 입력의 성격을 보고 추론한다. **인물·갈림길이 분명하면 사례 기반 문제**, **시작 질문 한 줄로 끝나는 형태가 필요하면 상황 제시문**이다. 추론이 모호하면 교사에게 묻고 진행한다.

한 단원에 둘 다 있을 때 학습이 가장 깊어진다 — 시작에는 상황 제시문, 마무리에는 사례 기반 문제. 두 자료가 단원의 흐름을 양쪽에서 받쳐 준다.

## 입력

교사로부터 다음을 받는다.

### 사례 기반 문제 모드의 입력
- **단원**: 예) "<대수> 지수함수의 활용"
- **인물**: 나이·환경·고민의 종류 — 예) "23세 정수, 첫 직장 신입사원, 30년 적립 계획"
- **갈림길**: 2~3개의 선택지와 각 선택지의 합리적 근거 — 예) "A: 단리 4% / B: 적립식 펀드 7% 복리"
- **(선택) 단원 핵심 개념**: 학생이 사례 풀이에 사용해야 할 단원 개념. 명시 안 하면 단원에서 추론.

### 상황 제시문 모드의 입력
- **단원**: 예) "<대수> 지수함수의 활용"
- **시작 맥락**: 한두 문장의 현실 상황 — 예) "확진자가 일주일에 100→800명"
- **(선택) 탐구 방향**: 학생이 어떤 변수를 정의하길 바라는가

입력에 인물·갈림길이 부족하면(사례 기반 문제 모드의 경우) 교사에게 추가 정보를 요청한 뒤 진행한다. 인물 정보가 흐릿하면 학생이 사례 속 인물의 자리에 앉기 어려워진다.

## 워크플로우

### 1단계. 작성 기준 로드

다음 두 파일을 읽는다.

- `resources/사례_표준_6원칙.md` — 사례 작성의 6가지 원칙 (인물·정보·갈림길·위치성·개념 강제·분량)
- `resources/사례_4가지_조건.md` — 좋은 사례 기반 문제의 4가지 조건 (자가 진단·비평 기준)

### 2단계. 작업 모드 결정

입력을 보고 사례 기반 문제 모드 또는 상황 제시문 모드를 결정한다. 모호하면 교사에게 한 줄로 확인한다.

> "사례 기반 문제(의사결정 과제)와 상황 제시문(탐구 진입점) 중 어느 형태가 좋을까요?"

### 3단계. 초안 작성

`사례_표준_6원칙.md`에 따라 초안을 작성한다. 사례 기반 문제 모드와 상황 제시문 모드가 각각 따라야 할 형식은 다르되, 6원칙은 두 모드 모두에 적용된다.

### 4단계. 자가 진단

`사례_4가지_조건.md`를 적용해 다음 형식의 자가 진단표를 사례 본문 직후에 출력한다.

```
[자가 진단표]
1. 한정된 정보 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (어떤 정보가 의도적으로 비어 있는지 명시)
2. 선택의 갈림길 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (2~3개 선택지와 각 선택지의 합리적 근거 한 줄씩)
3. 학생의 위치성 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (마지막 질문이 '당신이라면' 형태인지)
4. 단원 개념 강제 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (사례 풀이에 단원의 어떤 개념이 반드시 사용되는지)
5. 분량 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (사례 기반 문제는 A4 반 페이지, 상황 제시문은 한 단락 + 시작 질문)
```

자가 진단에서 모든 항목이 ✓이라면 교사에게 그대로 전달한다. △ 또는 ✗가 있다면 보완 후 다시 작성한다 (최대 2회 반복).

### 5단계. 비평가 모드 전환 (교사 요청 시)

교사가 다음과 같이 말하면 비평가 모드로 전환한다.

- "지금부터 비평가 역할로 전환해 줘"
- "비평가의 시각으로 검토해 줘"
- "subagents/비평가.md의 기준으로 점검해 줘"

이때는 `subagents/비평가.md`를 읽고 그 안에 정의된 비평가의 자세와 5항목 기준에 따라 검토 결과를 출력한다. 작가의 시점이 아니라 비평가의 시점에서 사례를 본다.

검토가 끝나면 다음 한 줄로 마친다.

> "이상으로 비평을 마친다. 작가 역할로 돌아간다."

### 6단계. 수정 (교사 요청 시)

교사가 "권고대로 수정해 줘"라고 요청하면 작가 모드로 돌아와 비평가의 권고를 반영한 수정본을 작성한다. 수정 후 다시 자가 진단표를 함께 출력한다.

## 출력 형식

### 사례 기반 문제 모드의 출력

```markdown
## [사례 제목 — 인물 이름이 들어가는 짧은 제목]

[1~2문장으로 인물의 나이·환경·고민을 즉시 보여 주는 도입]

[갈림길 1] — 한 줄 설명, 합리적 근거 한 줄

[갈림길 2] — 한 줄 설명, 합리적 근거 한 줄

[(선택) 갈림길 3] — 한 줄 설명

[주변 인물의 다른 의견을 통한 갈림길 강화 — 한 단락]

(1) [단원 개념을 사용해야 풀리는 계산 또는 분석 질문]
(2) [그 계산 결과의 의미를 학생이 자기 언어로 설명하게 하는 질문]
(3) [당신이라면 어떻게 할 것인가 — 학생의 가치관을 드러내는 질문]
```

### 상황 제시문 모드의 출력

```markdown
## [짧은 제목]

[한두 문장의 현실 맥락 + 충격적/흥미로운 사실]

[학생을 끌어들이는 시작 질문 — 답이 정해지지 않음]

[탐구의 시작점이 될 만한 첫 질문 한두 개]
```

자가 진단표는 위 본문 다음에 한 줄 띄고 배치한다.

## 회피 사항

이 skill은 다음을 하지 않는다.

- 학생이 읽고 사고하는 일반 텍스트 자료 만들기 (reading-material skill의 영역)
- 학생이 종이에 답을 적는 활동지 만들기 (activity-sheet skill의 영역)
- 학생이 조작하는 인터랙티브 도구 만들기 (interactive-visualizer skill의 영역)
- 자료의 사실 확인 (material-validator skill의 영역)
- 정답이 정해진 객관식 문제, 단순 계산 문제 — 이 skill은 의사결정 과제와 탐구 진입점만을 만든다

이 skill은 오직 "학생이 의사결정자의 자리에서 자기 가치관과 단원 개념을 함께 사용하게 하는 사례"만을 만든다.

## 작성 예시 (참고)

다음은 한 호출의 입력과 출력 골격이다.

**입력**:
- 단원: <대수> 지수함수의 활용
- 인물: 23세 정수, 첫 직장 신입사원, 매월 30만 원씩 30년 적립 계획
- 갈림길:
  - A 상품: 단리 연 4%
  - B 상품: 적립식 펀드, 장기 평균 연 7% 복리 (단, 한 해 마이너스 가능)

**출력의 골격**:

```
## 정수의 30년 — 첫 통장의 선택

23세 정수가 첫 직장에 들어갔다. 한 달에 손에 쥐는 돈에서
30만 원을 떼어 30년간 모으기로 했다. 은행은 두 가지 상품을
보여 주었다.

A 상품 — 단리 연 4%. 변동 없음. 30년 동안 안정적이다.

B 상품 — 적립식 펀드, 장기 평균 연 7% 복리. 단, 시장 변동에
따라 한 해에 마이너스가 날 수도 있다.

정수의 어머니는 "확실한 게 좋다"며 A를 권한다. 정수의 친구는
"장기로 보면 복리가 답"이라며 B를 권한다. 정수는 어느 쪽도
아직 결정하지 못했다.

(1) 두 상품에서 30년 후 정수의 통장에는 각각 얼마가 남는가?
    직접 계산해 보자.
(2) 두 결과의 차이는 어디에서 오는가? 단순히 이율 3%의 차이
    때문인가?
(3) 당신이 정수라면, 어떤 선택을 할 것인가? 그리고 그 선택을
    30년 후의 자기 자신에게 어떻게 설명할 것인가?
```

자가 진단표가 그 뒤에 따라 나온다.

이 골격은 강제 형식이 아니다. 단원과 인물에 따라 자유롭게 변형 가능하되, 6원칙과 4가지 조건이 모두 들어 있어야 한다.
