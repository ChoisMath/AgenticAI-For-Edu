# 좋은 사례 기반 문제의 4가지 조건 — 자가 진단표

이 자료는 case-based-problem skill이 작성한 초안을 자가 점검할 때 사용하는 진단표다.

도서 5-4절 나 절에서 정의한 4가지 조건을 그대로 옮긴 것이며, 각 조건마다 진단 질문, 통과 기준, 미통과 시 보완 방법을 함께 정리한다.

별다른 지침이 없으면 AI는 가장 익숙한 형태 — 모든 정보가 주어진 단순 계산 문제 — 로 회귀한다. 이 회귀를 방지하기 위해 작성 직후 다음 4가지 항목으로 자기 작업물을 점검한다.

---

## 조건 1. 한정된 정보

### 정의

사례는 학생에게 모든 답을 주지 않는다. 일부러 빠뜨린 정보, 학생이 추론과 가정으로 채워야 할 빈자리가 있다.

### 증상 (미통과 신호)

- 모든 변수가 명시되어 학생이 단순 대입만 하면 답이 나옴
- "단, X는 Y로 가정한다" 같은 안내가 사례 본문에 모두 들어가 있음
- 학생이 "어떤 정보가 더 필요한가"를 물을 자리가 없음

### 진단 질문

다음 세 가지 질문에 모두 "예"라고 답할 수 있어야 통과다.

1. 학생이 가정하거나 추가로 알아봐야 할 정보가 적어도 한 가지 있는가?
2. 그 빈자리가 학생의 사고를 가로막지 않고 자극하는가?
3. 빈자리가 너무 많아 학생이 출발점을 잃지는 않는가? (이 질문에는 "아니오"가 통과)

### 통과 기준

- 의도적으로 비워 둔 정보가 적어도 한 가지 명시 가능
- 그 빈자리가 학생의 직감과 결정에 영향을 미치는 종류임 (사소한 정보가 아님)
- 빈자리가 너무 많아 학생이 출발조차 못 하는 상태가 아님

### 미통과 시 보완

- 사례에서 한 가지 정보를 의도적으로 제거한다 (예: 인플레이션, 변동성 폭, 인물의 정확한 월급 등)
- 그 정보의 부재가 학생의 결정에 어떤 영향을 미치는지 마음속에서 시뮬레이션해 본다

### 자가 진단 출력 예

```
1. 한정된 정보 — ✓ 통과
   (의도적으로 비워둔 정보: 30년 인플레이션, 펀드 변동성 폭, 정수의 월급)
```

## 조건 2. 선택의 갈림길

### 정의

사례에는 정답 하나가 아니라 판단 영역이 있다. 학생은 A를 고를 수도, B를 고를 수도 있다. 둘 다 정답이 될 수 있고, 둘 다 부분적으로 틀릴 수도 있다.

### 증상 (미통과 신호)

- A는 명백히 좋고 B는 명백히 나쁜 형태
- 갈림길이 두 개가 아니라 사실상 하나 (다른 하나는 들러리)
- 작가가 마음속에 정답을 미리 정해 두고 있음

### 진단 질문

1. 갈림길 각각에 합리적 근거가 한 줄로 명시되어 있는가?
2. 어느 한쪽이 명백히 옳은 답이 되어 있지는 않은가?
3. 학생이 자기 가치관에 따라 다르게 선택할 수 있는 형태인가?

### 통과 기준

- 갈림길 2~3개가 명시됨
- 각 갈림길에 합리적 근거가 한 줄로 적혀 있음
- 학생의 가치관(안정 vs 수익, 단기 vs 장기 등)에 따라 다른 선택이 가능

### 미통과 시 보완

- 한쪽으로 기운 갈림길이라면, 약한 쪽의 근거를 보강한다
- 갈림길 각각에 "왜 이걸 선택할 만한가"를 한 줄로 추가한다
- 주변 인물의 다른 의견(부모·친구·동료)을 사례에 넣어 갈림길의 무게를 균형 있게 만든다

### 자가 진단 출력 예

```
2. 선택의 갈림길 — ✓ 통과
   - A: 안정성 (변동 없음, 마이너스 위험 0)
   - B: 장기 수익성 (30년 복리 효과)
   둘 다 합리적 근거가 있어 가치관에 따라 다른 선택 가능
```

## 조건 3. 학생의 위치성

### 정의

좋은 사례에서 학생은 관찰자가 아니라 의사결정자다. "다음 중 옳은 것은?"이 아니라 "당신이라면 어떻게 할 것인가?"가 사례의 마지막 질문이다.

### 증상 (미통과 신호)

- 마지막 질문이 "다음 중 옳은 것은?"
- 마지막 질문이 "어느 상품이 더 유리한가?"
- 마지막 질문이 "어떻게 해야 하는지 설명하시오"
- "당신이라면" 형태이지만 본문에서 이미 답을 시사함

### 진단 질문

1. 마지막 질문이 "당신이라면" 형태인가?
2. 학생이 자기 가치관을 드러내야 답할 수 있는 질문인가?
3. 학생마다 답이 다르게 나올 수 있는 질문인가?

### 통과 기준

- 마지막 질문이 명시적으로 "당신이라면", "당신이 [인물]이라면", "당신의 입장에서" 같은 형태
- 학생이 자기 가치관·자기 우선순위를 답에 드러내야 함
- 30명 학생이 답하면 답이 갈리는 종류의 질문

### 미통과 시 보완

- 마지막 질문을 "당신이라면 어떻게 할 것인가?"로 바꾼다
- 한 단계 더 들어가려면 "그 선택을 [미래 시점]의 자기 자신에게 어떻게 설명할 것인가?" 같은 변주 추가

### 자가 진단 출력 예

```
3. 학생의 위치성 — ✓ 통과
   마지막 질문이 "당신이 정수라면, 어떤 선택을 할 것인가?
   30년 후의 자기 자신에게 어떻게 설명할 것인가?"로 끝남
```

## 조건 4. 데이터로 답하게 한다 (단원 개념 강제)

### 정의

사례는 직관만으로 답하게 두지 않는다. 직관 → 계산 → 비교 → 판단의 흐름을 만든다. 단원의 핵심 개념이 답의 근거에 반드시 포함되도록 만든다.

### 증상 (미통과 신호)

- 사례를 풀 때 단원 개념을 안 써도 답이 나옴
- 일반 상식·도덕적 직관만으로 답할 수 있음
- 단원 개념이 "있으면 좋다" 정도이지 강제되지 않음

### 진단 질문

1. 단원의 어떤 핵심 개념이 사례 풀이에 사용되는가?
2. 그 개념을 사용하지 않으면 정말로 답을 낼 수 없는가?
3. 사례에 직관 → 계산 → 비교 → 판단의 흐름이 들어 있는가?

### 통과 기준

- 단원 개념의 이름을 명시적으로 적을 수 있음 (예: "지수함수의 적립식 복리 공식")
- 그 개념 없이는 사례의 첫 질문에 답할 수 없음
- 사례의 질문 (1)(2)(3) 흐름이 직관에서 의사결정으로 자연스럽게 이어짐

### 미통과 시 보완

- 사례를 풀 때 단원 개념의 사용이 필수가 되도록 첫 질문을 재작성
- (1)에서 "직접 계산하라" 같은 명시적 요구를 넣어 단원 개념 사용을 강제
- 직관·상식만으로 답할 수 있는 질문은 (2)나 (3)으로 옮기되, (1)은 단원 개념 강제 자리로 유지

### 자가 진단 출력 예

```
4. 단원 개념 강제 — ✓ 통과
   질문 (1) "두 상품의 30년 후 결과를 직접 계산해 보자"
   → 지수함수의 적립식 복리 공식 사용 없이는 답 불가
```

## 5번째 점검 항목 — 분량

위 4가지 조건은 사례의 본질을 점검한다. 여기에 형식적 점검 항목 하나를 더한다.

### 분량 점검

- **사례 기반 문제 모드**: A4 반 페이지 이내 (700~900자)
- **상황 제시문 모드**: 한 단락(200~300자) + 시작 질문(2~3개)

### 자가 진단 출력 예

```
5. 분량 — ✓ 통과
   사례 본문 약 820자 (A4 반 페이지 이내)
```

## 자가 진단 출력 형식 (정식)

skill은 사례 본문 작성 후 다음 형식으로 자가 진단표를 출력한다.

```
[자가 진단표]

1. 한정된 정보 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (어떤 정보가 의도적으로 비어 있는지 한 줄)

2. 선택의 갈림길 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   - A: (한 줄 근거)
   - B: (한 줄 근거)
   (한쪽으로 기울지 않은 균형 여부 한 줄)

3. 학생의 위치성 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (마지막 질문의 형태 한 줄)

4. 단원 개념 강제 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (사례 풀이에 사용되는 단원 개념 명시)

5. 분량 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (총 N자, 모드 기준 적정 여부)
```

## 진단 결과별 다음 행동

| 결과 | 다음 행동 |
|------|-----------|
| 모두 ✓ | 교사에게 사례 본문 + 자가 진단표 전달. 교사가 비평가 모드 호출 시 그때 비평가로 전환. |
| △가 1~2개 | 본문을 보완하여 다시 작성. 자가 진단을 다시 거친다 (최대 2회 반복). |
| ✗가 1개 이상 | 해당 조건을 중점적으로 보완. 특히 조건 3(위치성)이나 조건 4(개념 강제)의 ✗는 사례의 본질이 무너진 것이므로 전면 재작성을 고려. |

## 진단의 자세

자가 진단은 자기 작업물에 대한 검토다. 자기 작업을 너그럽게 보지 않는다.

- "대체로 괜찮은 것 같다"는 판정이 아니다 — ✓ 통과인지 △ 확인 필요인지를 분명히 가린다
- 통과 기준에 미달하면 미통과다 — 학생의 입장에서 판단한다
- 자가 진단의 목표는 통과시키는 것이 아니라, **학생이 정말로 의사결정자의 자리에 앉을 수 있는 사례를 만드는 것**이다

특히 다음을 자기 자신에게 거듭 묻는다.

> 30명의 학생이 이 사례를 풀면 답이 갈리는가? 갈리지 않는다면 — 모두가 같은 답에 도달한다면 — 그 사례는 갈림길을 잃은 것이다.
