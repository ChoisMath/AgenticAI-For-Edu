# 자가 진단 기준

작성한 양면 활동지를 교사에게 전달하기 전, 작가 시점에서 다음 9기준으로 점검한다. 도입형 4기준 + 정리형 4기준 + 종합 박스 1기준이다. 각 기준에 대해 ✓ 통과 / △ 확인 필요 / ✗ 미통과 중 하나를 매기고 한 줄 근거를 적는다.

---

## 앞면 (도입형) — 4기준

### 기준 1. Connect 정답형 회상이 아닌가

#### 점검 질문
Connect 칸의 안내 문구를 읽었을 때, 학생이 "정답이 있는 시험"이라고 느낄 가능성이 있는가?

| 매김 | 조건 |
|---|---|
| ✓ 통과 | 학생이 자유롭게 떠올린 것을 적을 수 있는 열린 질문. "떠오르는 것", "느끼는 것", "이미 알고 있다고 생각하는 것" 같은 어휘 |
| △ 확인 필요 | 정답이 있는 듯한 어휘("정의", "공식", "값", "법칙")가 섞여 있음 |
| ✗ 미통과 | 빈칸 채우기, 단답형, 객관식, "다음을 쓰시오" 형태 |

### 기준 2. Extend 결과 답하기 강요가 아닌가

#### 점검 질문
Extend 칸이 "오늘 배울 결과를 미리 답하시오"가 되어 있지는 않은가?

| 매김 | 조건 |
|---|---|
| ✓ 통과 | 학생이 자기 사고의 확장 방향을 자유롭게 상상해 적을 수 있는 형태. "어떻게 넓어질 것 같은가", "무엇이 더해질 것 같은가" 같은 어휘 |
| △ 확인 필요 | 결과를 답하라는 어조가 섞여 있음. "예상해 보시오", "추측해 보시오"는 △ 경계 |
| ✗ 미통과 | "그래프를 그려 보시오", "구해 보시오", "정의를 적어 보시오" 등 결과를 미리 답하게 하는 형태 |

### 기준 3. Challenge 학생의 진짜 미지를 받는가

#### 점검 질문
Challenge 칸이 "교사가 낸 도전 문제 칸"이 아니라 "학생의 미지를 받는 칸"인가?

| 매김 | 조건 |
|---|---|
| ✓ 통과 | 학생 본인의 미지·궁금증·막힘을 자기 언어로 적을 수 있는 열린 질문 |
| △ 확인 필요 | 교사가 미리 답을 정해둔 듯한 질문이 섞여 있음. "핵심 질문은?" 같은 형태 |
| ✗ 미통과 | "도전 문제를 풀어라" 형태, 정답이 있는 심화 문제, 교사가 정한 함정 질문 |

### 기준 4. 앞면 세 칸이 핵심 개념 하나로 일관되는가

#### 점검 질문
Connect, Extend, Challenge 세 칸이 같은 핵심 학습 내용을 중심으로 일관되어 있는가?

| 매김 | 조건 |
|---|---|
| ✓ 통과 | 세 칸 모두 교사가 입력한 핵심 학습 내용을 중심으로 자연스럽게 이어짐 |
| △ 확인 필요 | 한 칸이 핵심 개념에서 살짝 벗어나거나, 너무 좁거나 너무 넓음 |
| ✗ 미통과 | 세 칸이 서로 다른 주제를 다룸. 또는 핵심 학습 내용과 연결이 안 됨 |

## 뒷면 (정리형) — 4기준

### 기준 5. Connect (정리형)이 단순 요약이 아닌가

#### 점검 질문
정리형 Connect 칸이 학습 내용 요약이 아니라, 새로 배운 것과 기존 지식의 연결을 묻는가?

| 매김 | 조건 |
|---|---|
| ✓ 통과 | "새 개념이 내가 이미 알던 것과 어디에서 만나는가" 형태의 연결 질문 |
| △ 확인 필요 | 연결을 묻는 듯하지만 사실상 요약을 요구하는 어조가 섞여 있음. "오늘 배운 내용 중 ~을 적으시오" 같은 형태 |
| ✗ 미통과 | "오늘 배운 내용을 요약하시오", "오늘 학습한 정의를 적으시오" 형태 |

### 기준 6. Extend (정리형)이 단순 학습 결과 나열이 아닌가

#### 점검 질문
정리형 Extend 칸이 학습 결과 나열이 아니라, 사고의 확장 방향을 묻는가?

| 매김 | 조건 |
|---|---|
| ✓ 통과 | "나의 사고가 어떤 방향으로 넓어졌는가", "이전과 비교해 무엇을 다르게 보는가" 형태 |
| △ 확인 필요 | 새 방향을 묻는 듯하지만 사실상 학습 결과 나열을 유도함. "새로 알게 된 점을 적되, 자기 생각도 함께"는 △ 경계 |
| ✗ 미통과 | "오늘 새로 알게 된 내용을 적으시오" 형태의 단순 결과 나열 |

### 기준 7. Challenge (정리형)이 단순 어려움 토로가 아닌가

#### 점검 질문
정리형 Challenge 칸이 어려움 토로가 아니라, 남은 의문 또는 새로 생긴 탐구 거리를 묻는가?

| 매김 | 조건 |
|---|---|
| ✓ 통과 | "여전히 풀리지 않는 의문, 새로 떠오른 질문" 형태의 탐구 지향 질문 |
| △ 확인 필요 | 의문을 묻는 듯하지만 어려움 토로로 흐를 수 있는 어조. "잘 이해되지 않는 부분은?" |
| ✗ 미통과 | "어려웠던 부분은?", "다 이해하지 못한 부분은?" 형태 |

### 기준 8. 뒷면 세 칸이 앞면과 같은 핵심 개념을 중심으로 일관되는가

#### 점검 질문
정리형의 세 칸이 앞면(도입형)과 같은 핵심 학습 내용을 중심으로 일관되어 있는가?

| 매김 | 조건 |
|---|---|
| ✓ 통과 | 앞·뒤 여섯 칸 모두 같은 핵심 개념을 중심으로 일관됨 |
| △ 확인 필요 | 정리형 한 칸이 핵심 개념에서 살짝 벗어남. 또는 정리형이 도입형과 다른 표현으로 핵심을 가리킴 |
| ✗ 미통과 | 정리형이 앞면과 다른 주제를 다룸 |

## 종합 박스 — 1기준

### 기준 9. 종합 박스가 사고의 변화를 묻는가

#### 점검 질문
종합 박스가 단순 소감이 아니라, 학생의 사고가 시작점에서 도착점으로 어떻게 옮겨갔는지를 묻는가?

| 매김 | 조건 |
|---|---|
| ✓ 통과 | "앞면의 나와 지금의 나를 비교", "사고가 어디에서 어디로 옮겨갔는가" 형태 |
| △ 확인 필요 | 비교를 묻는 듯하지만 단순 소감으로 흐를 수 있는 어조 |
| ✗ 미통과 | "소감을 적으시오", "오늘 학습이 도움이 되었는가?" 형태 |

---

## 자가 진단 후 행동

- 9항목 모두 ✓ → 교사에게 그대로 전달
- 1~3항목이 △ 또는 ✗ → 해당 부분을 보완해 다시 작성한 뒤 다시 자가 진단 (최대 2회 반복)
- 4항목 이상이 △ 또는 ✗ → 한 번에 모두 고치려 하지 말고, 도입형 / 정리형 / 종합 박스 중 가장 문제가 큰 영역부터 손본 뒤 다시 진단
- 2회 반복해도 통과하지 못하면 → 교사에게 진단 결과와 함께 그대로 전달하고 어느 부분을 보완해야 하는지 명시
