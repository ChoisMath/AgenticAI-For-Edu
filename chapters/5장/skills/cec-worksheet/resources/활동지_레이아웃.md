### 마크다운 작성 시 유의 사항

- 학생을 향한 안내 문구는 모두 평어가 아닌 **존중하는 어조**(~봅시다, ~좋습니다)로 적는다.
- 지난 시간 회상 박스는 **반드시 구체적**으로 — 단원명만 쓰지 말고 그날 다룬 핵심 표현·식·예시를 한두 가지 적어 학생이 그 시간을 다시 떠올릴 수 있게 한다.
- 앞면과 뒷면은 같은 핵심 학습 내용을 중심으로 짜되, 안내 문구의 시점이 다르다. 앞면은 "곧 배울 것에 대한 예감", 뒷면은 "방금 배운 것에 대한 회고와 새 의문".
- 앞면 메시지 띠("채점되지 않습니다")와 뒷면 메시지 띠("단순 요약이 아닙니다")는 **반드시** 활동지 상단에 시각적으로 분명히 보이도록 둔다.
- 앞면 활동지에는 회귀 박스를 두지 않는다. 회귀는 뒷면 종합 박스에서 일어난다.
- 빈 줄 공간은 마크다운에서는 ` ``` `로 감싼 빈 코드 블록으로 표현한다 (실제 docx에서는 빈 표 셀 또는 빈 단락으로 변환됨).

## 2부. docx 디자인 가이드 — 웹페이지 카드 느낌, 양면 인쇄

### 핵심 콘셉트

종이 양면에 인쇄되지만 학생의 눈에는 **웹페이지의 카드 UI**처럼 보이게 한다. 각 단계를 색상으로 구분된 카드로 구현하고, 모서리의 둥근 느낌은 음영과 여백으로 흉내 낸다. 앞면과 뒷면은 같은 색상 체계로 시각적 일관성을 유지하되, 메시지 띠와 헤더 표기로 시점의 차이를 분명히 한다.

### 페이지 설정

```javascript
// A4, 0.75인치 여백 — 각 면이 정확히 한 페이지에 들어가야 함
// docx-js는 한 section 안에서 children에 PageBreak를 두면 다음 페이지로 넘어감
size: { width: 11906, height: 16838 },  // A4 (DXA)
margin: { top: 1080, right: 1080, bottom: 1080, left: 1080 }  // 0.75인치
```

총 2페이지를 한 section의 children에 순차로 배치한다. 페이지 1(앞면)과 페이지 2(뒷면) 사이에 PageBreak를 둔다.

```javascript
// 앞면 콘텐츠 ...
new Paragraph({ children: [new PageBreak()] }),  // 양면 구분
// 뒷면 콘텐츠 ...
```

### 색상 팔레트 (16진수)

| 단계 | 헤더 띠 (진한 색) | 본문 배경 (옅은 색) | 사용처 |
|---|---|---|---|
| Connect | `2563EB` (파랑) | `DBEAFE` (옅은 파랑) | 앞·뒷면 모두 |
| Extend | `7C3AED` (보라) | `EDE9FE` (옅은 보라) | 앞·뒷면 모두 |
| Challenge | `EA580C` (주황) | `FED7AA` (옅은 주황) | 앞·뒷면 모두 |
| 회상 박스 | `64748B` (회색) | `F1F5F9` (옅은 회색) | 앞면만 |
| 메시지 띠 (앞면) | — | `FEF3C7` (옅은 노랑) | 앞면 |
| 메시지 띠 (뒷면) | — | `E0F2FE` (옅은 하늘) | 뒷면 |
| 종합 박스 | `0F766E` (청록) | `CCFBF1` (옅은 청록) | 뒷면 종합 박스 |

### 폰트

```javascript
default: { document: { run: { font: "맑은 고딕", size: 22 } } }  // 11pt
```

- 활동지 제목 (페이지 헤더): 맑은 고딕 Bold, 14pt
- 카드 헤더 (단계명): 맑은 고딕 Bold, 13pt, 색상 흰색 (`FFFFFF`)
- 학생 안내 문구: 맑은 고딕 Italic, 10pt, 색상 `475569` (어두운 회색)
- 학생 기재란 안내선: 색상 `94A3B8` (옅은 회색)

### 카드 표 구조 — 각 단계당 한 표

각 단계(Connect/Extend/Challenge)는 **2행 1열**의 표로 만든다. 앞면과 뒷면 모두 같은 구조.

```javascript
new Table({
  width: { size: 9746, type: WidthType.DXA },  // A4 - 좌우 여백 (11906 - 2160 = 9746)
  columnWidths: [9746],
  rows: [
    // 1행: 헤더 띠 (진한 색 + 흰 글씨)
    new TableRow({
      children: [new TableCell({
        width: { size: 9746, type: WidthType.DXA },
        shading: { fill: "2563EB", type: ShadingType.CLEAR },
        margins: { top: 100, bottom: 100, left: 200, right: 200 },
        children: [new Paragraph({
          children: [new TextRun({
            text: "Connect — 내가 이미 알고 있는 것",
            bold: true, color: "FFFFFF", size: 26
          })]
        })]
      })]
    }),
    // 2행: 본문 (옅은 색 배경 + 안내 문구 + 빈 줄)
    new TableRow({
      children: [new TableCell({
        width: { size: 9746, type: WidthType.DXA },
        shading: { fill: "DBEAFE", type: ShadingType.CLEAR },
        margins: { top: 200, bottom: 300, left: 240, right: 240 },
        children: [
          // 안내 문구 (작은 회색 이탤릭)
          new Paragraph({
            spacing: { after: 200 },
            children: [new TextRun({
              text: "이 주제와 관련해 ...",
              italics: true, color: "475569", size: 20
            })]
          }),
          // 학생이 적을 빈 줄 — 앞면 4줄, 뒷면 4줄
          ...학생기재란_4줄(),
        ]
      })]
    })
  ]
})
```

### 학생 기재란 (빈 줄) 만드는 법

학생이 손글씨로 적을 줄은 단락 하단에 보더를 그어 노트 줄을 만든다.

```javascript
function 학생기재란_4줄() {
  const 빈줄 = () => new Paragraph({
    border: { bottom: { style: BorderStyle.SINGLE, size: 4, color: "CBD5E1", space: 1 } },
    spacing: { before: 0, after: 240, line: 480, lineRule: "exact" },
    children: [new TextRun({ text: "" })]
  });
  return [빈줄(), 빈줄(), 빈줄(), 빈줄()];
}
```

### 종합 박스 (뒷면 하단)

종합 박스는 청록색 큰 카드로 구현한다. 학생이 두세 줄 적을 공간을 둔다.

```javascript
new Table({
  width: { size: 9746, type: WidthType.DXA },
  columnWidths: [9746],
  rows: [
    new TableRow({
      children: [new TableCell({
        shading: { fill: "0F766E", type: ShadingType.CLEAR },
        margins: { top: 100, bottom: 100, left: 200, right: 200 },
        children: [new Paragraph({
          children: [new TextRun({
            text: "🔁 종합 — 나의 사고는 어디에서 어디로 옮겨갔는가",
            bold: true, color: "FFFFFF", size: 26
          })]
        })]
      })]
    }),
    new TableRow({
      children: [new TableCell({
        shading: { fill: "CCFBF1", type: ShadingType.CLEAR },
        margins: { top: 200, bottom: 300, left: 240, right: 240 },
        children: [
          new Paragraph({
            spacing: { after: 200 },
            children: [new TextRun({
              text: "앞면에 적었던 나의 사고와 비교해 봅시다. 한두 줄로 적어 봅시다.",
              italics: true, color: "475569", size: 20
            })]
          }),
          ...학생기재란_3줄(),  // 종합 박스는 3줄로 충분
        ]
      })]
    })
  ]
})
```

### 페이지별 전체 구성 순서

#### 페이지 1 (앞면)
1. **상단 헤더** — "CEC 활동지 — [단원명] (수업 시작)", 학년·반·번호·이름·날짜 한 줄
2. **회상 박스** (회색 카드, 1행 표, 본문 3~4줄)

4. **메시지 띠** (옅은 노란색 배경 `FEF3C7`, "이 활동지는 채점되지 않습니다 ...")
5. **Connect 카드** (파랑, 학생 기재란 4줄)
6. **Extend 카드** (보라, 학생 기재란 4줄)
7. **Challenge 카드** (주황, 학생 기재란 4줄)

#### **PageBreak**

#### 페이지 2 (뒷면)
8. **상단 헤더** — "CEC 활동지 — [단원명] (수업 정리)", 학년·반·번호·이름 한 줄
9. **오늘 학습한 내용** (한 줄 텍스트, 가운데 정렬, 11pt Bold)
10. **메시지 띠** (옅은 하늘색 배경 `E0F2FE`, "수업이 끝났습니다. 이 면은 단순 요약이 ...")
11. **Connect (정리형) 카드** (파랑, 학생 기재란 4줄)

13. **Challenge (정리형) 카드** (주황, 학생 기재란 4줄)
14. **종합 박스** (청록, 학생 기재란 3줄)

각 요소 사이에는 단락 spacing으로 8pt 정도 간격을 둔다.

### 한 페이지에 담기 위한 압축 팁

- 학생 기재란 줄 수: 카드별 4줄, 종합 박스 3줄 (꽉 차면 카드별 3줄, 종합 박스 2줄로 줄임)
- 줄 높이: `line: 480` (약 24pt) — 손글씨에 충분
- 카드 간 간격: spacing.after 160 (8pt)
- 페이지 여백: 0.75인치
- 회상 박스: 3줄로 충분 (4줄이면 한 페이지를 넘기 쉬움)

각 면이 정확히 한 페이지에 들어가지 않으면 학생 기재란 줄 수를 먼저 줄인다.

### docx 작성 절차

1. 위 구조에 따라 `script.js` 파일을 작성한다 (`npm install -g docx`로 설치된 라이브러리 사용).
2. `node script.js`로 실행해 `.docx` 파일을 생성한다.
3. `python /mnt/skills/public/docx/scripts/office/validate.py output.docx`로 검증한다.
4. `present_files` 도구로 교사에게 파일을 전달한다.

### docx 작성 시 유의 사항

- `ShadingType.CLEAR`만 사용 (SOLID 쓰면 검정 배경)
- 표 너비는 `WidthType.DXA`로 — `PERCENTAGE` 금지
- `columnWidths` 합 = 표 width와 정확히 일치
- 셀에도 `width` 따로 설정 — 이중 너비 필요
- `PageBreak`는 반드시 `Paragraph` 안에 넣는다 — 단독 사용 시 invalid XML
- 이모지는 폰트가 지원하지 않을 수 있으니 본문에서는 사용 금지. 헤더 띠의 색상으로 단계를 구분
- 마크다운 초안의 이모지(🔵🟣🟠🔁)는 **시각적 가이드용**이며 docx에서는 색상 띠가 그 역할을 대신한다
