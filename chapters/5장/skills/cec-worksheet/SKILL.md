# cec-worksheet skill

한 차시 또는 한 단원의 시작과 끝에서 학생의 사고가 어떻게 변하는지를 종이 위에 드러내는 양면 활동지를 생성한다.

## 핵심 원칙

이 skill은 다음 두 가지 변형을 한 종이의 앞뒤에 배치한 위에 만들어졌다.

> **앞면 (도입형 CEC)**: Project Zero의 CEC를 뒤집어 "곧 배울 것"에 대해 학생이 자기 known/unknown 영역을 그려보게 하는 메타인지 도구로 사용한다.
>
> **뒷면 (정리형 CEC)**: Project Zero 원본의 의도대로 "방금 배운 것"에 대해 학생이 사고를 정리하고 새로 생긴 의문을 마주하게 하는 도구로 사용한다.
>
> **종합 박스**: 뒷면 하단에서 학생이 앞면을 다시 보며 자기 사고가 어디에서 어디로 옮겨갔는지 한두 줄로 적게 한다.

학생은 수업 시작 시 앞면에 자신의 출발점을 그리고, 수업이 끝난 뒤 뒷면에 자신의 도착점을 그리며, 종합 박스에서 그 둘을 비교한다. 한 종이 위에 수업 전후의 두 자아가 만난다.

가장 큰 함정: 도입형은 학생이 "정답을 내야 하는 시험"이라고 느끼면 망가지고, 정리형은 학생이 "단순 요약을 적는 칸"이라고 느끼면 망가진다. 이 skill은 두 시점이 서로 다른 사고를 요구한다는 메시지를 활동지의 구조와 안내 문구로 분명히 전달해야 한다.

## 입력

교사로부터 다음을 받는다.

- **단원**: 예) "지수함수의 그래프"
- **학년**: 예) "고2"
- **차시 위치**: 예) "단원 1차시 (도입~정리)", "전개 5차시 중 3차시"
- **핵심 학습 내용**: 예) "지수함수 y=a^x의 그래프 개형과 점근선"
- **앞선 수업 사례**: 예) "지난 시간에는 거듭제곱과 거듭제곱근의 성질을 복습하며 a^0=1, a^(-n)=1/a^n을 다뤘음"

입력이 일부 비어 있으면 교사에게 한 번 묻는다. 추정으로 채우지 않는다.

한 번 명령으로 앞면(도입형)과 뒷면(정리형) 모두를 생성한다. 따로따로 만드는 모드는 없다.

## 워크플로우

### 1단계. 작성 기준 로드

다음 두 파일을 모두 읽어 도입형과 정리형 각각의 원칙을 작성의 기준으로 삼는다.

- `resources/CEC_도입형_원칙.md` — 앞면용
- `resources/CEC_정리형_원칙.md` — 뒷면용

### 2단계. 마크다운 초안 작성

`resources/활동지_레이아웃.md`의 양면 레이아웃에 따라 활동지를 마크다운으로 작성한다. 한 출력에 앞면과 뒷면을 모두 담는다.

#### 앞면 (도입형) 레이아웃 핵심
- 헤더 (단원 / 학년·반·번호·이름 / 날짜)
- 앞선 수업 회상 박스 (3~4줄, 학생이 다시 떠올릴 수 있도록 구체적으로)
- 오늘의 학습 주제 한 줄
- "이 활동지는 채점되지 않습니다" 메시지 띠
- Connect / Extend / Challenge 세 카드 — 각 카드 안에 학생을 향한 구체적인 안내 질문 + 학생이 적을 빈 줄

#### 뒷면 (정리형) 레이아웃 핵심
- 헤더 (앞면과 동일한 학생을 위해 동일하게 표시, "수업 정리" 표기)
- 오늘 학습한 내용 한 줄 (앞면과 동일한 핵심 학습 내용)
- "수업이 끝났습니다. 앞면에 적은 나의 사고와 비교하며 지금의 나를 적어 봅시다" 메시지 띠
- Connect (정리형) / Extend (정리형) / Challenge (정리형) 세 카드 — PZ 원본 의도에 따라
- **종합 박스** — "나의 사고는 어디에서 어디로 옮겨갔는가" 한두 줄

학생을 향한 안내 문구는 평어가 아니라 **존중하는 어조**로 적되, 도입형은 "정답이 없다", 정리형은 "단순 요약이 아니라 사고의 변화"라는 메시지를 분명히 담는다.

### 3단계. 자가 진단

`resources/자가진단_기준.md`를 읽어 작성한 활동지를 9가지 항목으로 자가 진단한다. 도입형 4항목, 정리형 4항목, 종합 박스 1항목으로 구성된다.

진단 결과는 본문 직후에 다음 형식으로 출력한다.

```
[자가 진단표]

▼ 앞면 (도입형)
1. Connect 정답형 회상이 아닌가 — ✓ / △ / ✗ (한 줄 근거)
2. Extend 결과 답하기 강요가 아닌가 — ✓ / △ / ✗ (한 줄 근거)
3. Challenge 학생의 진짜 미지를 받는가 — ✓ / △ / ✗ (한 줄 근거)
4. 앞면 세 칸이 핵심 개념 하나로 일관되는가 — ✓ / △ / ✗ (한 줄 근거)

▼ 뒷면 (정리형)
5. Connect (정리형)이 단순 요약이 아닌가 — ✓ / △ / ✗ (한 줄 근거)
6. Extend (정리형)이 단순 학습 결과 나열이 아닌가 — ✓ / △ / ✗ (한 줄 근거)
7. Challenge (정리형)이 단순 어려움 토로가 아닌가 — ✓ / △ / ✗ (한 줄 근거)
8. 뒷면 세 칸이 앞면과 같은 핵심 개념을 중심으로 일관되는가 — ✓ / △ / ✗ (한 줄 근거)

▼ 종합 박스
9. 종합 박스가 사고의 변화를 묻는가 — ✓ / △ / ✗ (한 줄 근거)
```

자가 진단에서 모든 항목이 ✓이라면 교사에게 그대로 전달한다. 하나라도 △ 또는 ✗가 있다면 그 부분을 보완하여 다시 작성한 뒤 다시 자가 진단을 거친다 (최대 2회 반복).

### 4단계. 교사에게 전달 + docx 변환 의향 확인

마크다운 초안(앞면 + 뒷면)과 자가 진단표를 함께 출력한 뒤 다음과 같이 묻는다.

> "마크다운 초안입니다. 검토 후 docx 파일로 변환을 원하시면 말씀해 주세요. 웹페이지 느낌의 디자인을 입혀 양면 인쇄용 활동지(2페이지 한 파일)로 만들어 드립니다."

### 5단계. docx 변환 (교사 요청 시)

교사가 "docx로 만들어 줘", "활동지 파일로 변환해 줘" 등의 요청을 하면 다음 두 가지를 함께 따른다.

1. `/mnt/skills/public/docx/SKILL.md`를 먼저 읽어 docx 작성 규칙을 확인한다.
2. `resources/활동지_레이아웃.md`의 **docx 디자인 가이드** 섹션을 따라 양면 인쇄용 활동지를 한 docx 파일로 생성한다.

디자인 핵심:
- 앞면(도입형)과 뒷면(정리형)은 같은 색상 체계 — Connect (파랑), Extend (보라), Challenge (주황)
- 셀 배경 음영 + 색상 띠로 "웹페이지 카드" 느낌 구현
- 산세리프 한글 폰트 (맑은 고딕), 본문 11pt
- 각 면이 정확히 A4 한 페이지에 들어가도록 콤팩트 레이아웃
- 두 페이지 사이는 PageBreak로 구분 (양면 인쇄 시 자연스럽게 앞·뒷면이 됨)
- 뒷면 종합 박스는 청록색 큰 카드 — 학생이 두세 줄 적을 공간

생성 후 `present_files` 도구로 교사에게 파일을 전달한다.

### 6단계. 비평가 모드 전환 (교사 요청 시)

교사가 다음과 같이 말하면 비평가 모드로 전환한다.

- "지금부터 비평가 역할로 전환해 줘"
- "비평가 역할로 점검해 줘"
- "subagents/비평가.md의 기준으로 검토해 줘"

이때는 `subagents/비평가.md`를 읽고 그 안에 정의된 비평가의 자세와 9항목 기준에 따라 검토 결과를 출력한다. 작가의 시점이 아니라 비평가의 시점에서 자료를 본다.

검토가 끝나면 다음 한 줄로 마친다.

> "이상으로 비평을 마친다. 작가 역할로 돌아간다."

### 7단계. 수정 (교사 요청 시)

교사가 "권고대로 수정해 줘"라고 요청하면 작가 모드로 돌아와 비평가의 권고를 반영한 수정본을 작성한다. 수정 후 다시 자가 진단표를 함께 출력한다.

## 출력 형식

각 작성마다 다음 두 가지를 함께 출력한다.

1. **마크다운 활동지 초안** — 앞면 (도입형) + 뒷면 (정리형) + 종합 박스
2. **자가 진단표** — 9항목 (도입형 4 + 정리형 4 + 종합 박스 1)

교사 요청 시 추가:
3. **docx 활동지 파일** — 웹페이지 느낌의 디자인이 입혀진 2페이지 양면 인쇄용 파일

## 회피 사항

이 skill은 다음을 하지 않는다.

- 도입형 단독 또는 정리형 단독 활동지 만들기 — 이 skill은 양면 한 쌍을 한 번에 생성
- 학생이 풀어야 하는 문제를 어느 칸에든 박아 넣기 — 모든 칸은 학생의 사고를 받기 위한 칸이지 교사가 낸 문제 칸이 아님
- 사고 유발 읽기 자료 만들기 (reading-material skill의 영역)
- 자료의 사실 확인 (material-validator skill의 영역)
- IB Math 활동지 또는 영어 병기 활동지 — 이 skill은 일반 고등학교 수학·한국어 전용
- 세 페이지 이상의 활동지 — 정확히 양면(2페이지) 안에 모두 들어가야 함

이 skill은 오직 "한 차시 또는 한 단원의 시작과 끝을 한 종이의 앞뒤로 잇는 양면 활동지"만을 만든다.
