# 4장. 수업 준비 단계에서 바로 쓰는 활용법

> 에이전틱 AI와 함께 수업 준비의 전체 흐름을 걸어본다. '단원명 하나를 입력하면 수업에 필요한 것이 한 번에 나온다' — 이것이 이 장에서 도달하고자 하는 지점이다.

---

## 이 장에 포함된 자료

각 파일 페이지의 **우측 상단 복사 아이콘(📋)** 한 번이면 전체 내용이 클립보드에 들어갑니다. 그대로 claude.ai의 해당 영역에 붙여넣으세요.

### 📋 Project 지침 (한 번만 등록)

| 파일 | 용도 |
|---|---|
| **[프로젝트_지침.md](./프로젝트_지침.md)** | claude.ai 새 Project의 **Project Instructions** 영역에 1회 등록. 교사가 단원명만 입력하면 **6단계 워크플로우 (성취기준 분석 → 핵심 개념 → 학습 목표 → 탐구 질문 → 활동안 → 학습 자료)** 를 거쳐 한 편의 **수업 설계서**를 산출하도록 구성됨. 자기 점검표·차시 조정·보충/심화 분기까지 포함. |

> **사전 준비**: Project에 해당 교과의 **2022 개정 교육과정 문서(PDF)** 를 함께 업로드해야 합니다. 지침이 이 문서를 분석 기준으로 삼습니다.

### 💬 후속 프롬프트 (수업 설계서가 나온 뒤 사용)

위에서 만든 Project의 같은 채팅에서, 차별화 자료가 필요할 때 채팅창에 그대로 붙여넣어 사용합니다.

| 파일 | 용도 |
|---|---|
| **[보충자료생성_프롬프트.md](./보충자료생성_프롬프트.md)** | 핵심 개념 이해에 어려움을 겪는 학생용. **단계별 체크리스트 · 핵심 용어 카드 · 시작점을 낮춘 탐구 활동**을 갖춘 활동지를 생성. '쉬운 버전' 같은 낙인 표현 대신 '차근차근 접근하는 활동지'로 학생 자존감을 보호. |
| **[심화자료생성_프롬프트.md](./심화자료생성_프롬프트.md)** | 핵심 개념을 충분히 이해한 학생용. **조건 변경 탐구 · 역방향 사고 · 비판적 평가** 중 단원에 맞는 방향을 골라, 교육과정 범위를 벗어나지 않은 채 '더 깊이' 다루는 활동지를 생성. 동료에게 설명하는 서술란과 열린 질문 포함. |

## 사용 흐름

```
1. claude.ai에서 새 Project 생성
   ├─ 해당 교과의 [2022 개정 교육과정 PDF] 를 Project Files에 업로드
   └─ [프로젝트_지침.md] 복사 → Project Instructions 에 붙여넣기

2. Project 안의 새 채팅에서 단원명 입력
   예) "등비수열의 활용 — 원리합계"
   ↓
   6단계 워크플로우 자동 실행 → 수업 설계서 한 편 출력

3. 차별화 자료가 필요할 때, 같은 채팅에 이어서:
   ├─ 학습이 더딘 학생용  → [보충자료생성_프롬프트.md] 복사 → 채팅창에 붙여넣기
   └─ 더 깊이 갈 학생용  → [심화자료생성_프롬프트.md] 복사 → 채팅창에 붙여넣기
```

## 추가 요청 패턴 (수업 설계서가 나온 뒤)

수업 설계서를 한 번 받은 다음에는 자연어로 부분 수정이 가능합니다 (프로젝트 지침에 미리 학습되어 있음):

- "활동안을 모둠 활동 중심으로 바꿔 줘" → 활동안만 재생성
- "탐구 질문이 너무 어려워. 더 쉽게 해 줘" → 탐구 질문만 재생성
- "이걸 2차시로 확장해 줘" → 활동안을 2차시 구성으로 재생성
- "평가 루브릭도 만들어 줘" → 추가 항목 생성
