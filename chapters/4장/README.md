# 4장. 수업 준비 단계에서 바로 쓰는 활용법

> 에이전틱 AI와 함께 수업 준비의 전체 흐름을 걸어본다. '단원명 하나를 입력하면 수업에 필요한 것이 한 번에 나온다' — 이것이 이 장에서 도달하고자 하는 지점이다.

---

## 이 장에 포함된 자료

각 파일 페이지의 **우측 상단 복사 아이콘(📋)** 한 번이면 전체 내용이 클립보드에 들어갑니다. 그대로 claude.ai의 해당 영역에 붙여넣으세요.

### 📋 Claude Project 지침

| 파일 | 용도 |
|---|---|
| **[프로젝트_지침.md](./프로젝트_지침.md)** | claude.ai에서 새 Project를 만들 때 **Project Instructions** 영역에 붙여 넣는 시스템 프롬프트 |

### 💬 작업별 프롬프트 템플릿

같은 Project 안에서, 각 작업이 필요할 때 채팅창에 붙여 넣어 사용합니다.

| 파일 | 용도 |
|---|---|
| **[보충자료생성_프롬프트.md](./보충자료생성_프롬프트.md)** | 학습 부진 학생을 위한 보충 자료 생성용 프롬프트 |
| **[심화자료생성_프롬프트.md](./심화자료생성_프롬프트.md)** | 심화 학습이 필요한 학생을 위한 자료 생성용 프롬프트 |

---

## 사용 흐름

```
1. 위 [프로젝트_지침.md] → 페이지 열기 → 📋 복사
   └─ claude.ai에서 새 Project 생성 → Project Instructions 영역에 붙여넣기

2. 같은 Project로 들어가서 채팅 시작
   ├─ 보충 자료가 필요하면 → [보충자료생성_프롬프트.md] 복사 → 채팅창에 붙여넣기
   └─ 심화 자료가 필요하면 → [심화자료생성_프롬프트.md] 복사 → 채팅창에 붙여넣기
```

> 4장은 .md 프롬프트 파일만 제공합니다. Claude Skill 패키지(.zip)는 5장부터 등장합니다.
