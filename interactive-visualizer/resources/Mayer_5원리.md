# Mayer의 멀티미디어 학습 5원리

이 자료는 interactive-visualizer skill이 인터랙티브 도구를 설계할 때 따를 학습 이론적 근거다.

리처드 메이어(Richard Mayer)의 멀티미디어 학습 이론(Multimedia Learning Theory)은 화면 위에서 학습이 어떻게 일어나는가를 다룬다. 그가 정리한 12개 원리 중 인터랙티브 학습 도구 설계에 가장 직접적으로 적용되는 다섯 가지를 본 skill에서 활용한다.

이 다섯 원리는 "왜 어떤 도구는 학생의 사고를 일으키고, 어떤 도구는 그렇지 못한가"에 대한 학술적 답이다.

---

## 원리 1. 다중 표상 (Multimedia Principle)

> 같은 정보를 글·그림·수치 등 여러 표상으로 함께 제시할 때 학습이 더 잘 일어난다.

### 학습 도구에서의 적용

학생은 같은 개념을 다른 표상으로 동시에 만나야 깊이 이해한다. 인터랙티브 도구에서 가장 자연스러운 다중 표상의 형태는 다음 셋의 동시 표시다.

- **그래프** — 시각적 표상 (관계의 모양)
- **수치** — 양적 표상 (정확한 값)
- **슬라이더** — 조작적 표상 (변화의 매개)

학생이 슬라이더를 움직이면 그래프와 수치가 동시에 바뀐다. 세 표상이 하나의 손동작으로 연결될 때 학생의 머릿속에 개념의 입체적 모형이 만들어진다.

### 좋은 적용 예
- 지수함수 도구: 수식 (위쪽 표시) + 그래프 (중앙) + 현재 교차점 좌표 (우측)
- 통계 도구: 데이터 분포 (히스토그램) + 평균·표준편차 (수치) + 슬라이더로 분포 조작
- 화학 도구: 분자 모형 (3D 그림) + 결합 에너지 (수치) + 거리 슬라이더

### 점검 질문
- 학생이 같은 개념을 몇 가지 표상으로 동시에 만나는가?
- 한 표상을 바꾸면 다른 표상이 동시에 반응하는가?

### 미통과 신호
- 그래프만 있고 수치가 없음
- 수치만 있고 시각적 표상이 없음
- 슬라이더는 있으나 결과가 한 가지 형태로만 보임

## 원리 2. 일관성 (Coherence Principle)

> 학습에 무관한 정보는 줄일수록 학습이 좋아진다.

### 학습 도구에서의 적용

화면에 학습과 관계없는 요소가 많을수록 학생의 인지 자원이 분산된다. 학습 도구는 **장식이 아니라 학습**이 목적이다.

### 일관성을 해치는 흔한 요소
- 불필요한 색상 변화 (예: 그래프 배경에 그라데이션)
- 학습과 무관한 아이콘이나 일러스트
- 화려한 애니메이션 (학습의 핵심을 강조하지 않는 애니메이션)
- 광고처럼 보이는 헤더·푸터

### 좋은 적용 예
- 색상은 두세 가지로 제한 (예: 지수함수=파랑, 일차함수=주황, 강조=빨강)
- 배경은 단색 또는 옅은 그레이
- 애니메이션은 학습의 핵심 순간(교차점·변곡점)에만

### 점검 질문
- 화면에서 학습과 무관한 요소를 제거할 수 있는가?
- 학생의 시선을 학습 핵심으로 모으는가, 아니면 분산시키는가?

### 미통과 신호
- "예쁘게 보이려고" 추가된 요소가 있음
- 색상이 5가지 이상이고 각 색상의 의미가 분명하지 않음
- 학습 핵심이 아닌 곳에서 애니메이션이 일어남

---

## 원리 3. 신호화 (Signaling Principle)

> 학습의 핵심을 시각적으로 강조하는 신호가 있어야 한다.

### 학습 도구에서의 적용

학생이 학습 도구를 처음 만났을 때 "어디를 봐야 하는가"가 명확해야 한다. 모든 요소가 같은 비중으로 보이면 학생은 길을 잃는다.

### 좋은 신호화의 형태
- **굵은 색상 대비** — 핵심 요소(예: 두 함수의 교차점)는 다른 색상보다 진하게
- **크기 차이** — 중요 수치는 더 큰 글씨로
- **마커와 애니메이션** — 핵심 순간(교차점이 화면에 나타날 때)에 짧은 반짝임
- **순간적 강조** — 슬라이더를 움직이는 동안 변화하는 값이 잠시 색을 바꾸기

### 좋은 적용 예
- 두 함수의 교차점에 작은 동그라미 마커 + 화면에 처음 나타날 때 0.5초간 반짝임
- 현재 슬라이더 값이 본문 텍스트보다 1.5배 큰 글씨
- 학습 핵심 순간에만 색이 빨강으로 바뀌는 변수

### 점검 질문
- 학생이 처음 화면을 봤을 때 가장 먼저 시선이 가는 곳이 학습의 핵심인가?
- 학습 핵심 순간이 시각적으로 분명히 구분되는가?

### 미통과 신호
- 모든 요소가 같은 색·같은 크기
- 핵심 변화가 일어나도 화면에서 어떤 강조도 없음
- 강조가 곳곳에 너무 많아 어느 것이 진짜 핵심인지 모름

## 원리 4. 공간 근접성 (Spatial Contiguity Principle)

> 관련된 글과 그림은 가까이 배치할수록 학습이 좋아진다.

### 학습 도구에서의 적용

학생이 그래프를 보면서 수치를 확인하려고 시선을 멀리 돌려야 한다면, 그 사이에 인지 부하가 발생한다. 관련 정보는 같은 시야 안에 있어야 한다.

### 좋은 배치
- 그래프와 그래프의 핵심 좌표는 **같은 영역 안에** (그래프 옆에 좌표 표시)
- 슬라이더와 그 슬라이더의 현재 값은 **바로 옆에** (위가 아니라 옆)
- 탐구 질문과 답을 적는 박스는 **나란히 또는 바로 아래**

### 좋은 적용 예
- 슬라이더 옆에 큰 글씨로 현재 값: `b: 2.0` (슬라이더 바로 우측)
- 교차점 좌표를 그래프의 우측 상단 모서리에 (그래프 옆에)
- 탐구 질문 1, 2, 3과 답 박스가 같은 단락에

### 점검 질문
- 학생이 한 정보를 보면서 다른 정보를 확인하기 위해 시선을 크게 돌려야 하는가?
- 관련된 두 정보가 같은 시야 안에 있는가?

### 미통과 신호
- 슬라이더는 좌측 아래에, 현재 값은 우측 상단에 — 시선 이동 거리가 큼
- 그래프와 핵심 수치가 화면의 정반대 끝에
- 탐구 질문이 페이지 하단에, 답 박스는 페이지 상단에

## 원리 5. 양식 (Modality Principle)

> 시각·청각 채널을 분담시킬 때 학습이 좋아진다.

### 학습 도구에서의 적용

이 원리는 음성을 활용할 수 있는 환경에서 강하게 작동한다. 정적인 텍스트로 모든 정보를 전달하면 시각 채널만 과부하 상태가 된다. 일부를 음성으로 옮기면 두 채널이 분담된다.

### 학교 수업 환경에서의 현실

대부분의 인터랙티브 학습 도구는 **음성을 사용하지 않는다**. 교실 환경에서 음성이 켜진 도구를 30명 학생이 동시에 쓰면 혼란이 일어난다. 따라서 본 skill에서는 양식 원리를 다음과 같이 변형 적용한다.

### 변형 적용

- **시각 채널 안에서 부담 분산** — 글과 그림의 비중을 균형 있게
- **상호작용으로 채널 부담 감소** — 학생이 슬라이더를 움직이면서 보는 행위 자체가 한 채널의 부담을 다른 채널로 옮기는 효과
- **음성이 필요한 경우** — 시각 장애 학생을 위한 보조 자료로만 (필요 시 별도 작업)

### 점검 질문 (변형 적용 기준)

- 시각 정보가 한 화면에 너무 빽빽하게 들어 있지 않은가?
- 학생의 손동작(슬라이더 조작)이 인지 부하를 분담하는가?

### 일반적 통과

본 skill에서는 양식 원리는 대부분 "해당 없음" 또는 "통과"로 처리한다. 도구 자체가 음성을 쓰지 않기 때문이다. 다만 시각 정보의 과밀집 여부를 점검하는 차원에서는 항상 살핀다.

## 다섯 원리의 우선순위

학습 도구 설계 시 다섯 원리의 적용 우선순위는 다음과 같다.

| 우선순위 | 원리 | 이유 |
|---|---|---|
| 1 | **다중 표상** | 학습 도구의 존재 이유 그 자체. 빠지면 도구가 아님 |
| 2 | **공간 근접성** | 인지 부하 직접 영향. 흔히 간과됨 |
| 3 | **신호화** | 학습 핵심을 학생이 인지하는 데 결정적 |
| 4 | **일관성** | 자주 위반됨 (장식의 유혹) |
| 5 | **양식** | 음성 미사용 도구에서는 변형 적용 |

비평가 점검 시에도 이 우선순위에 따라 위중도를 다르게 본다. **다중 표상이나 공간 근접성에서 미통과**가 나오면 학습 효과가 크게 떨어지므로 즉시 수정 권고. **양식**의 미통과는 도구 특성상 흔히 해당 없음.
