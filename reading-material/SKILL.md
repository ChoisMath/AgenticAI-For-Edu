# reading-material skill

학생을 텍스트 앞에 멈춰 세우는 사고 유발 읽기 자료를 생성한다.

## 핵심 원칙

이 skill은 다음 한 가지 전제 위에 만들어졌다.

> 학생이 읽기 자료를 만났을 때 가장 중요한 일은 "정보를 받는 것"이 아니라 "잠시 멈추어 자기 생각을 들여다보는 것"이다.

이 멈춤을 자료의 구조로 설계하는 것이 이 skill의 역할이다.

## 입력

교사로부터 다음을 받는다.

- **단원**: 예) "<대수> 지수함수의 활용"
- **학년**: 예) "고2"
- **핵심 개념**: 예) "지수함수의 폭발적 증가"
- **중심 사례**: 예) "종이 한 장을 42번 접으면 달까지 닿는다"
- **분량**: 예) "800자 내외" (생략 시 800자 기본값)

## 워크플로우

### 1단계. 작성 기준 로드

`resources/3가지_조건.md`를 읽어 다음 세 가지 조건을 작성의 기준으로 삼는다.

1. 멈춤 지점 — 본문 중간에 ▶ 잠깐 표시 + 학생의 직관·경험과 충돌하는 질문 3곳
2. 예시·반례 병치 — 핵심 개념을 떠받치는 사례 + 그 사례를 다른 각도에서 비추는 반례
3. 열린 결말 — 마지막 문장은 학생을 향한 열린 질문

### 2단계. 초안 작성

교사가 입력한 단원·학년·핵심 개념·중심 사례를 바탕으로 본문을 작성한다.

- 분량은 요청된 글자 수의 ±10% 이내
- 멈춤 지점 3곳을 자연스러운 단락 사이에 배치
- 본문이 정보 전달 일변도가 되지 않도록 학생의 경험·직관에 호소하는 단락을 포함
- 전문 용어는 첫 등장 시 괄호 안에 일상 언어로 풀어 적음

### 3단계. 자가 진단

`resources/4가지_문제_진단.md`를 읽어 작성한 본문을 네 가지 항목으로 자가 진단한다.

진단 결과는 다음 형식으로 본문 직후에 출력한다.

```
[자가 진단표]
1. 설명 일변도 회피 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄 근거)
2. 멈춤 지점 3곳 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄 근거)
3. 예시·반례 병치 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄 근거)
4. 열린 결말 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄 근거)
```

자가 진단에서 모든 항목이 ✓이라면 교사에게 그대로 전달한다. 하나라도 △ 또는 ✗가 있다면 그 부분을 보완하여 다시 작성한 뒤 다시 자가 진단을 거친다 (최대 2회 반복).

### 4단계. 비평가 모드 전환 (교사 요청 시)

교사가 다음과 같이 말하면 비평가 모드로 전환한다.

- "지금부터 비평가 역할로 전환해 줘"
- "비평가 역할로 점검해 줘"
- "subagents/비평가.md의 기준으로 검토해 줘"

이때는 `subagents/비평가.md`를 읽고 그 안에 정의된 비평가의 자세와 4항목 기준에 따라 검토 결과를 출력한다. 작가의 시점이 아니라 비평가의 시점에서 자료를 본다.

검토가 끝나면 다음 한 줄로 마친다.

> "이상으로 비평을 마친다. 작가 역할로 돌아간다."

### 5단계. 수정 (교사 요청 시)

교사가 "권고대로 수정해 줘"라고 요청하면 작가 모드로 돌아와 비평가의 권고를 반영한 수정본을 작성한다. 수정 후 다시 자가 진단표를 함께 출력한다.

## 출력 형식

각 작성마다 다음 두 가지를 함께 출력한다.

1. **본문** — 멈춤 지점이 ▶ 잠깐 표시로 구분된 형태
2. **자가 진단표** — 4항목

## 회피 사항

이 skill은 다음을 하지 않는다.

- 학생이 직접 답을 적는 활동지 형태로 만들기 (그 일은 activity-sheet skill의 영역)
- 학생이 조작하는 인터랙티브 도구 만들기 (interactive-visualizer skill의 영역)
- 의사결정 사례 만들기 (case-based-problem skill의 영역)
- 자료의 사실 확인 (material-validator skill의 영역)

이 skill은 오직 "학생이 읽고 멈추어 생각하게 하는 텍스트"만을 만든다.
