# AI 생성 읽기 자료의 4가지 문제 진단표

이 자료는 reading-material skill이 작성한 초안을 자가 점검할 때 사용하는 진단표다.

별다른 지침이 없으면 AI는 가장 익숙한 형태 — 매끈하고 닫힌 설명문 — 으로 회귀한다. 이 회귀를 방지하기 위해 작성 직후 다음 4가지 항목으로 자기 작업물을 점검한다.

---

## 문제 1. 설명 일변도

### 증상

- 처음부터 끝까지 정의 → 예시 → 결론으로 흐름
- 학생의 사고가 개입할 자리가 없음
- 정보 전달이 목적인 글로 보임
- 본문이 학생을 향해 묻지 않고, 일방적으로 전달함

### 진단 질문

다음 세 가지 질문에 모두 "예"라고 답할 수 있어야 통과다.

1. 본문에서 학생이 자기 경험을 떠올릴 지점이 있는가?
2. 본문 안에 "왜?" 또는 "어떻게?" 같은 질문이 등장하는가?
3. 본문이 학생에게 무언가를 묻는 순간이 있는가?

### 통과 기준

- 본문이 정보 전달과 사고 유발을 함께 수행한다
- 적어도 한 곳에서 학생의 직감·경험에 호소한다
- 본문 전체가 일방적 설명문이 아니다

### 미통과 시 보완

설명 일변도라면 다음 중 하나를 시도한다.

- 본문 중간에 "당신이라면 어떻게 답하겠는가?" 같은 한 줄 추가
- 추상적 정의 대신 구체적 사례로 도입 다시 쓰기
- 결론 대신 학생을 향한 질문으로 단락 마무리

## 문제 2. 멈춤 지점 없음

### 증상

- ▶ 잠깐 표시가 0개, 1개, 또는 2개
- 멈춤 지점이 있더라도 단순 개념 확인 질문
- 본문이 한 호흡으로 끝까지 흐름

### 진단 질문

1. ▶ 잠깐 표시가 정확히 3개인가? (정확히 3개여야 함)
2. 각 멈춤 지점의 질문이 학생의 경험·직관과 충돌하는가?
3. 멈춤 지점을 빼도 본문이 자연스럽게 읽히는가? (자연스럽게 읽힌다면 잘못 끼운 멈춤 지점)

### 통과 기준

- 멈춤 지점이 정확히 3개
- 각 질문이 본문 사실과 학생 직관 사이의 충돌을 만든다
- 멈춤 지점이 본문 흐름의 자연스러운 일부가 된다

### 미통과 시 보완

- 멈춤 지점 수가 부족하면 추가 (3개가 될 때까지)
- 단순 확인 질문은 충돌형으로 다시 작성
- 멈춤 지점이 어색하게 끼어 있다면 자리를 옮긴다

## 문제 3. 예시·반례 없음

### 증상

- 단일 사례만 길게 설명
- 두 사례가 있어도 같은 방향으로 강화 (서로 대조하지 않음)
- 추상적 정의만 있고 구체적 사례 없음
- 사례는 있으나 반례가 없거나 분량이 매우 적음

### 진단 질문

1. 본문에서 핵심 개념을 떠받치는 구체적 사례가 있는가?
2. 그 사례를 깨거나 다른 각도에서 비추는 반례가 함께 있는가?
3. 두 사례가 같은 변수 하나만 다른 설정인가? (비교의 명료성)

### 통과 기준

- 사례 1과 반례 1이 본문 안에 함께 있다
- 두 사례의 대조가 학생에게 보이도록 배치되어 있다
- 두 사례의 분량이 비슷하다

### 미통과 시 보완

- 반례가 없다면 추가
- 두 사례가 같은 방향이라면, 한쪽을 반대 방향 사례로 교체
- 반례가 너무 짧다면 사례와 비슷한 분량으로 확장

## 문제 4. 닫힌 결말

### 증상

- 마지막 문장이 결론 진술 ("그러므로 ~이다")
- 마지막 문장이 정의 확정 ("이것이 ~의 정의이다")
- 마지막 문장이 다음 시간 안내 ("다음에는 ~를 배운다")
- 마지막 문장이 ?로 끝나지만 답이 본문 안에 있는 닫힌 질문

### 진단 질문

1. 마지막 문장이 ?로 끝나는가?
2. 그 질문에 답이 학생마다 다를 수 있는가?
3. 학생이 그 질문을 들고 다음 활동(활동지·시각 자료·사례)으로 갈 수 있는가?

### 통과 기준

- 마지막 문장이 학생을 향한 열린 질문이다
- 답이 학생마다 다를 수 있다
- 다음 자료로 자연스럽게 이어진다

### 미통과 시 보완

- 결론 진술이라면 그 결론이 함의하는 질문으로 바꿔 마침
- 정의 확정이라면 그 정의가 학생의 일상에 어떻게 닿는지를 묻는 질문으로 바꿈
- 단순 안내라면 본문 핵심 개념에 대한 학생의 자기 답을 요청하는 질문으로 바꿈

## 자가 진단 출력 형식

skill은 본문 작성 후 다음 형식으로 자가 진단표를 출력한다.

```
[자가 진단표]

1. 설명 일변도 회피
   ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄로 그렇게 판단한 근거)

2. 멈춤 지점 3곳
   ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄로 그렇게 판단한 근거)

3. 예시·반례 병치
   ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄로 그렇게 판단한 근거)

4. 열린 결말
   ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄로 그렇게 판단한 근거)
```

---

## 진단 결과별 다음 행동

| 결과 | 다음 행동 |
|------|-----------|
| 모두 ✓ | 교사에게 본문 + 자가 진단표 전달. 교사가 비평가 모드 호출 시 그때 비평가로 전환. |
| △가 1개 이상 | 본문을 보완하여 다시 작성. 자가 진단을 다시 거친다. (최대 2회 반복) |
| ✗가 1개 이상 | 해당 항목을 중점적으로 보완. 보완이 어려우면 교사에게 추가 정보를 요청. |

---

## 진단의 자세

자가 진단은 자기 작업물에 대한 검토다. 자기 작업을 너그럽게 보지 않는다.

- "대체로 괜찮은 것 같다"는 판정이 아니다 — ✓ 통과인지, △ 확인 필요인지를 분명히 가린다
- 통과 기준에 미달하면 미통과다 — 학생의 입장에서 판단한다
- 자가 진단의 목표는 통과시키는 것이 아니라, **학생이 정말로 멈추어 생각할 수 있는 자료를 만드는 것**이다
