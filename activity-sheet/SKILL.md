# activity-sheet skill

학생의 사고 흐름을 종이 위에서 시각화하는 활동지를 생성한다.

## 핵심 원칙

이 skill은 다음 한 가지 전제 위에 만들어졌다.

> 활동지는 학생이 답을 채우는 도구가 아니라, 학생의 사고가 어디서 어떻게 움직였는지 드러내는 도구다.

이 전제를 받아들이면 활동지의 모든 결정이 달라진다. 정의를 묻는 문항이 줄어들고, "예상한 답과 실제 답의 차이"를 묻는 문항이 늘어난다. 답을 적는 칸 옆에 짝과 비교하는 칸이 함께 놓인다. 마지막에 "오늘 배운 점"이 아니라 "오늘 내 생각이 어떻게 바뀌었는지"를 적는다.

## 입력

교사로부터 다음을 받는다.

- **단원**: 예) "<대수> 지수함수의 활용"
- **차시**: 예) "1차시" (생략 시 1차시 기본)
- **짝이 되는 읽기 자료의 핵심 질문/사실**: 예) "종이를 42번 접으면 달까지 닿는다"
- **활동의 축이 되는 과제**: 예) "수련이 매일 두 배로 자란다. 30일째 가득 찬다면 절반이 덮인 날은?"
- **분량**: 예) "A4 한 장" (생략 시 A4 한 장 기본)

## 워크플로우

### 1단계. 작성 기준 로드

다음 두 파일을 읽는다.

- `resources/4단_구조_설계.md` — '예상–확인–설명–재해석' 4단의 흐름과 각 단계의 역할
- `resources/세_층위_분포.md` — 수용형·구조화형·탐구형의 정의와 비율 기준

### 2단계. 4단 구조의 활동지 초안 작성

다음 6원칙에 따라 작성한다.

1. **4단 구조를 기본 틀로**. 예상–확인–설명–재해석이 활동지 전체에 일관되게 나타난다.
2. **수용형 문항은 최대 20%**. 나머지는 구조화형과 탐구형이 중심이다.
3. **모든 문항에 짝 두 개**. '내 생각을 쓰는 칸'과 '짝과 비교하는 칸'이 짝으로 들어간다.
4. **마지막 성찰 칸**. "오늘 배운 점"이 아닌 "수업 시작할 때 내 답과 지금 내 답의 차이"를 적는다.
5. **1차시 5문항 이내**. 적은 문항에 깊이 머무는 것이 빠르게 지나치는 것보다 낫다.
6. **종이 형태가 기본**. 인쇄해 나누어 줄 수 있는 마크다운 양식으로 출력. 디지털 변환은 별도 작업.

### 3단계. 자가 진단

`resources/세_층위_분포.md`를 참고해 작성한 활동지를 5항목으로 자가 진단한다.

진단 결과는 다음 형식으로 활동지 직후에 출력한다.

```
[자가 진단표]
1. 4단 구조의 완전성 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄 근거)
2. 세 층위 분포 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (수용형 N개 / 구조화형 N개 / 탐구형 N개)
3. 짝 비교 칸의 존재 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄 근거)
4. 성찰 칸의 구체성 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (한 줄 근거)
5. 문항 수 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (총 N문항)
```

자가 진단에서 모든 항목이 ✓이라면 교사에게 그대로 전달한다. 하나라도 △ 또는 ✗가 있다면 그 부분을 보완하여 다시 작성한 뒤 다시 자가 진단을 거친다 (최대 2회 반복).

### 4단계. 비평가 모드 전환 (교사 요청 시)

교사가 다음과 같이 말하면 비평가 모드로 전환한다.

- "지금부터 비평가 역할로 전환해 줘"
- "비평가 역할로 점검해 줘"
- "subagents/비평가.md의 기준으로 검토해 줘"

이때는 `subagents/비평가.md`를 읽고 그 안에 정의된 비평가의 자세와 5항목 기준에 따라 검토 결과를 출력한다. 작가의 시점이 아니라 비평가의 시점에서 활동지를 본다.

검토가 끝나면 다음 한 줄로 마친다.

> "이상으로 비평을 마친다. 작가 역할로 돌아간다."

### 5단계. 수정 (교사 요청 시)

교사가 "권고대로 수정해 줘"라고 요청하면 작가 모드로 돌아와 비평가의 권고를 반영한 수정본을 작성한다. 수정 후 다시 자가 진단표를 함께 출력한다.

## 출력 형식

### 활동지 본문 형식 (마크다운)

```markdown
# [단원명] [차시] 활동지

학년 ___반 ___번 이름 _____________

## 오늘의 과제
[과제 한 단락]

---

### [예상] 1. [문항 텍스트]

내 생각:
□ _________________________________
□ _________________________________

짝과 비교:
□ 같은 점: _________________________
□ 다른 점: _________________________

---

### [확인] 2. [문항 텍스트]
(같은 짝 구조 반복)

---

### [설명] 3. [문항 텍스트]
(같은 짝 구조 반복)

---

### [재해석] 4. [문항 텍스트]
(같은 짝 구조 반복)

---

### 오늘의 성찰
수업 시작할 때 내가 예상한 답:
□ _________________________________

수업이 끝난 지금 내 답:
□ _________________________________

두 답 사이에 무엇이 달라졌는가:
□ _________________________________
```

각 문항 앞의 `[예상]`, `[확인]`, `[설명]`, `[재해석]`은 4단 구조를 학생이 명시적으로 인지할 수 있도록 항상 적는다.

### 자가 진단표 형식

활동지 본문 다음에 한 줄 띄고 위 [자가 진단표] 형식 그대로 출력한다.

## 회피 사항

이 skill은 다음을 하지 않는다.

- 학생이 읽고 사고하는 텍스트 자료 만들기 (그 일은 reading-material skill의 영역)
- 학생이 조작하는 인터랙티브 도구 만들기 (interactive-visualizer skill의 영역)
- 의사결정 사례 만들기 (case-based-problem skill의 영역)
- 자료의 사실 확인 (material-validator skill의 영역)
- 디지털 활동지(HTML 아티팩트) 직접 생성 — 본 skill의 종이 출력본을 받은 뒤 별도 변환 작업으로 처리

이 skill은 오직 "학생이 종이 위에서 자기 사고를 시각화할 수 있는 활동지"만을 만든다.

## 작성 예시 (참고)

다음은 4단 구조가 잘 적용된 활동지의 골격 예시다.

**단원**: <대수> 지수함수의 활용 / 1차시
**과제**: "수련이 매일 두 배로 자라 30일째 연못이 가득 찬다면, 연못의 절반이 덮인 날은?"

```
[예상] 1. 위 과제를 읽고, 계산하지 말고 직감으로 답해 보자.
        몇 일째에 절반이 덮였을 것 같은가?

[확인] 2. 30일째 연못의 수련 수와 29일째 수련 수를
        직접 계산해 비교해 보자. (수련은 매일 2배로 늘어남)

[설명] 3. 1번에서 적은 예상과 2번의 실제 답 사이에 차이가
        있었는가? 차이가 있었다면, 왜 그런 차이가 생겼는지
        자기 언어로 설명해 보자.

[재해석] 4. 우리 주변의 어떤 현상이 같은 함정을 가지는가?
         "지금까지는 별 일 없었는데 갑자기 큰 일이 일어났다"
         고 느껴지는 일을 하나 떠올려 적어 보자.
```

각 문항 옆에는 '내 생각'과 '짝과 비교' 두 칸이 함께 배치된다. 마지막에는 성찰 칸이 따로 놓인다.

이 골격은 강제 형식이 아니다. 단원과 과제에 따라 자유롭게 변형 가능하되, 4단의 흐름과 5항목 기준이 모두 반영되어야 한다.
