# 활동지의 4단 구조 — 예상·확인·설명·재해석

이 자료는 activity-sheet skill이 활동지를 작성할 때 따를 4단 구조의 흐름과 각 단계의 역할을 정의한다.

활동지의 흐름은 임의가 아니다. **학생의 사고가 자연스럽게 흐르는 순서**를 따른다. 이 순서를 흐트리면 학생은 답을 채우는 데 집중하고, 자기 사고를 들여다볼 기회를 잃는다.

---

## 4단 구조의 의미

```
예상 → 확인 → 설명 → 재해석
```

각 단계는 학생의 사고 한 단면을 드러낸다.

| 단계 | 학생이 하는 일 | 드러나는 사고 |
|---|---|---|
| **예상** | 자기 직감으로 먼저 답한다 | 학생의 출발점 — 무엇을 알고 있는지, 어떤 직관을 가지고 있는지 |
| **확인** | 실제 자료·계산·관찰로 답을 본다 | 사실 — 학생의 직관과 어디서 만나고 어디서 어긋나는지 |
| **설명** | 예상과 확인 사이의 차이를 자기 말로 정리한다 | 학생의 메타인지 — 자기 사고의 위치를 자기가 안다 |
| **재해석** | 이 과정을 자기 일상의 다른 현상에 연결한다 | 학생의 일반화 — 학습이 자기 삶의 다른 자리로 옮겨간다 |

---

## 단계별 상세 설계

### 1단계. 예상 (Predict)

#### 역할

학생이 본격 학습에 들어가기 전 **자기 직감을 종이 위에 붙잡아 두는** 단계다. 이 단계가 없으면 학생은 자기가 무엇을 모르는지조차 모른 채 답을 받아들이게 된다.

#### 좋은 예상 문항의 조건

- **계산을 못 하게 한다** — "지금은 계산하지 말고", "직감으로", "느낌으로" 같은 표현으로 명시한다
- **답이 학생마다 다를 수 있다** — 정답 하나가 정해진 문항은 예상 단계가 아니다
- **학생의 직관이 본문 사실과 충돌할 가능성이 큰 지점에 둔다** — 그 충돌이 다음 단계의 동력이 된다

#### 예상 문항의 형식

```
[예상] 1. (과제를 읽고) 계산하지 말고 직감으로 답해 보자.
        ___________ (자기 답)
```

#### 회피해야 할 형태

- ❌ "다음 중 옳은 것은?" — 정답을 고르는 형식
- ❌ "지수함수의 정의를 쓰시오" — 본문에서 답을 찾는 수용형 (이건 확인 단계의 영역)
- ❌ "예측해 보세요. 답은 N입니다" — 답을 미리 알려 줌

### 2단계. 확인 (Check)

#### 역할

학생이 직접 계산·관찰·자료 분석을 통해 **실제 답을 만나는** 단계다. 이 단계의 핵심은 답을 외우게 하는 것이 아니라, 예상과 실제 사이의 거리를 학생이 직접 측정하게 하는 것이다.

#### 좋은 확인 문항의 조건

- **학생이 직접 계산하거나 관찰한다** — 답을 그냥 알려 주지 않는다
- **단원의 핵심 개념을 사용해야 풀린다** — 직관만으로 풀리면 단원과의 연결이 끊긴다
- **결과를 예상과 비교할 수 있는 형식이다** — 이 비교가 다음 단계의 출발점이 된다

#### 확인 문항의 형식

```
[확인] 2. 30일째 수련 수와 29일째 수련 수를 직접 계산해
        비교해 보자. (수련은 매일 2배로 늘어남)

        30일째: ___________
        29일째: ___________
        둘의 비율: ___________
```

#### 회피해야 할 형태

- ❌ "정답: 29일째에 절반" — 답을 미리 줌
- ❌ "선생님이 알려준 공식으로 풀어 보세요" — 자기 사고가 아닌 따라 적기

### 3단계. 설명 (Explain)

#### 역할

학생이 자기 머릿속의 변화를 **자기 언어로 표현하는** 단계다. 메타인지의 자리다. 이 단계가 빠지면 학생은 답을 외우고 끝난다. 이 단계가 있으면 학생은 자기 사고의 모양을 자기가 본다.

#### 좋은 설명 문항의 조건

- **예상과 확인을 비교하게 한다** — "1번의 답과 2번의 답 사이에…"
- **차이가 왜 생겼는지를 묻는다** — "왜 그런 차이가 생겼는가?"
- **자기 언어로 적게 한다** — 정답이 정해진 형식이 아닌 자유 서술

#### 설명 문항의 형식

```
[설명] 3. 1번 예상과 2번 확인 사이에 차이가 있었는가?
        차이가 있었다면, 왜 그런 차이가 생겼는지 자기
        언어로 설명해 보자.

        ___________________________________________
        ___________________________________________
```

#### 회피해야 할 형태

- ❌ "차이의 이유는 다음 중 무엇인가?" — 객관식
- ❌ "차이를 설명하시오" — 비교 대상이 흐릿함
- ❌ "느낀 점을 적으시오" — 메타인지가 아닌 감상

### 4단계. 재해석 (Reframe)

#### 역할

학생이 이 학습을 **자기 일상의 다른 자리로 옮겨 보는** 단계다. 일반화의 자리다. 이 단계가 있어야 학습이 활동지 밖으로 나간다.

#### 좋은 재해석 문항의 조건

- **학생 자신의 사례를 적게 한다** — "당신 주변에서…", "당신의 경험에서…"
- **본문의 개념을 일상으로 옮긴다** — 추상에서 구체로
- **답이 학생마다 완전히 다르다** — 정답이 하나면 재해석이 아니다

#### 재해석 문항의 형식

```
[재해석] 4. 우리 주변의 어떤 현상이 같은 함정을 가지는가?
         "지금까지는 별 일 없었는데 갑자기 큰 일이 일어났다"
         고 느꼈던 일을 하나 떠올려 적어 보자.

         ___________________________________________
         ___________________________________________
```

#### 회피해야 할 형태

- ❌ "이 단원의 개념을 정리하시오" — 본문 회귀
- ❌ "오늘 배운 점을 적으시오" — 모호함
- ❌ "다음에는 무엇을 배울지 적으시오" — 외부 안내

## 4단 구조의 변형 — 단원 특성에 따른 조정

4단 구조는 강제 형식이 아니다. 단원의 특성에 따라 다음 변형이 가능하다.

### 변형 1: 두 단계가 합쳐지는 경우

탐구가 짧은 단원에서는 [예상]과 [확인]이 한 문항에 합쳐질 수 있다.

```
[예상·확인] 1. 직감으로 먼저 답해 본 뒤, 그 답을 실제 계산과
            비교해 보자.
            내 직감의 답: __________
            실제 계산의 답: __________
```

### 변형 2: 한 단계가 깊이 들어가는 경우

핵심 사고가 [설명] 단계에 집중되는 단원에서는 [설명]을 두 문항으로 나눌 수 있다.

```
[설명-1] 3. 차이가 있었는가? 차이를 한 문장으로 적어 보자.
[설명-2] 4. 그 차이가 왜 생겼는지 자기 언어로 설명해 보자.
```

### 변형 3: 단원이 끝나는 차시

마지막 차시에서는 [재해석] 단계를 단원 전체에 대한 종합 성찰로 확장한다.

```
[재해석] 5. 이 단원에서 당신의 생각이 어떻게 바뀌었는가?
         단원 시작 전과 지금의 차이를 자기 언어로 적어 보자.
```

## 짝 비교 칸의 위치

활동지에서 학생이 답을 적는 모든 칸 옆에는 **짝과 비교하는 칸**이 함께 놓인다. 4단의 모든 단계에 공통으로 적용된다.

```
[단계명] N. 문항 텍스트

내 생각:
□ _________________________________

짝과 비교:
□ 같은 점: _________________________
□ 다른 점: _________________________
```

이 짝 비교 칸이 있는 이유는 단순하다.

학생의 사고는 혼자만의 것이 머무르면 자라지 않는다. 짝과 비교하는 순간 학생은 자기 답이 어디서 같고 어디서 다른지를 본다. 그 봄이 곧 자기 사고에 대한 메타인지다.

---

## 성찰 칸의 위치와 형식

활동지의 마지막에는 4단과 별도로 **성찰 칸**이 놓인다.

```
### 오늘의 성찰

수업 시작할 때 내가 예상한 답:
□ _________________________________

수업이 끝난 지금 내 답:
□ _________________________________

두 답 사이에 무엇이 달라졌는가:
□ _________________________________
```

성찰 칸의 핵심은 **"오늘 배운 점"이 아니라 "내 생각의 변화"**를 적게 하는 것이다. 학생이 지식을 얻은 것이 아니라 **자기 자신이 변한 것**을 의식하게 한다.

---

## 4단 구조가 무너지는 신호

다음 중 하나라도 해당하면 활동지가 4단 구조를 잃은 것이다.

- 모든 문항이 "정답을 적으시오" 형식이다 → [예상]이 빠졌다
- 학생이 답을 그냥 받아들이고 있다 → [확인]이 자기 활동이 아니다
- 차이를 자기 언어로 적는 자리가 없다 → [설명]이 빠졌다
- 마지막 문항이 단원 정리에 머무른다 → [재해석]이 빠졌다
- 짝과 비교하는 칸이 없다 → 사고가 혼자만의 것에 갇힌다

이 신호 중 하나라도 보이면 자가 진단에서 미통과로 판정한다.
