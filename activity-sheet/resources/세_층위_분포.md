# 활동지 문항의 세 층위 — 수용형·구조화형·탐구형

이 자료는 activity-sheet skill이 활동지의 문항을 분류하고 비율을 점검할 때 사용하는 기준이다.

활동지의 깊이는 문항 수가 아니라 문항의 층위에 달려 있다. 수용형 일색의 활동지는 "빈칸 채우기"가 되고, 탐구형 일색의 활동지는 학생이 출발점을 찾지 못한다. 세 층위의 적절한 분포가 활동지의 결을 만든다.

---

## 세 층위의 정의

### 1. 수용형 (Receptive)

**정의**: 본문이나 수업에서 제시한 정의·사실·공식을 학생이 받아들여 그대로 적는 문항.

**예시**:
- "지수함수의 정의를 쓰시오."
- "y = aˣ에서 a의 조건은?"
- "복리의 공식을 적으시오."

**역할**: 핵심 개념을 짧게 점검한다. 활동지의 도입 또는 핵심 사실 확인 자리에 한두 개 두는 것이 적절하다.

**위험**: 수용형이 활동지의 중심이 되면 학생은 본문을 옮겨 적는 일에 머무른다. 사고는 일어나지 않는다.

### 2. 구조화형 (Structured)

**정의**: 학생이 본문에서 익힌 개념을 **단계별 사고 흐름**에 따라 적용하는 문항. 답은 어느 정도 정해져 있되, 거기에 도달하는 과정에 학생의 사고가 들어간다.

**예시**:
- "30일째 가득 차는 연못이라면 29일째에는 얼마나 덮여 있을지 직감으로 예상한 뒤, 실제 계산과 비교해 차이를 설명하시오."
- "y = 2ˣ과 y = 5x의 그래프가 어디서 만나는지 찾고, 그 교차점 이후에 어느 함수가 더 큰지 설명하시오."
- "매월 30만 원, 30년 적립 시 단리 4%와 복리 7%의 결과를 각각 계산하고, 두 결과의 차이가 어디에서 오는지 적으시오."

**역할**: 활동지의 중심을 이룬다. **4단 구조의 [확인]·[설명] 단계가 대부분 구조화형**이다.

**특징**: 답은 정해져 있되, 학생이 자기 사고 과정을 보이게 만든다. 비교, 단계별 풀이, 차이의 설명이 핵심 동사다.

### 3. 탐구형 (Inquiry)

**정의**: 학생이 본문 개념을 **자기 일상이나 자기 가치관에 적용**하는 문항. 답이 학생마다 다르고, 정답이 하나가 아니다.

**예시**:
- "우리 주변의 어떤 현상이 같은 함정을 가지는가? 자신의 경험에서 한 사례를 떠올려 적어 보자."
- "당신이 정수라면, 단리 4%와 복리 7% 중 어떤 상품을 선택할 것인가? 그 선택을 30년 후의 자기 자신에게 어떻게 설명할 것인가?"
- "수업 시작할 때 예상한 답과 지금 내 답 사이에 무엇이 달라졌는가? 자기 언어로 적어 보자."

**역할**: 활동지의 끝에 두어 학습이 본문 밖으로 옮겨가게 한다. **4단 구조의 [예상]과 [재해석] 단계가 대부분 탐구형**이다.

**특징**: 답이 학생마다 다르다. 자기 경험·자기 가치관·자기 언어가 답의 핵심이다.

## 세 층위의 비율 기준

### 권장 분포

| 층위 | 비율 | 5문항 활동지의 경우 |
|---|---|---|
| 수용형 | **최대 20%** | 0~1개 |
| 구조화형 | 40~60% | 2~3개 |
| 탐구형 | 30~40% | 1~2개 |

### 왜 수용형은 최대 20%인가

수용형이 절반을 넘으면 활동지는 "정답을 적는 종이"가 된다. 학생의 사고가 드러날 자리가 없다. 본문을 그대로 옮겨 적는 작업에 머문다.

수용형은 핵심 개념을 한 번 짧게 점검하는 자리에만 둔다. 활동지의 중심이 되어서는 안 된다.

### 왜 구조화형이 중심인가

구조화형은 학생이 자기 사고 과정을 종이 위에 펼쳐 놓게 한다. 단계별로 답을 적으면서 학생은 자기가 어디서 막혔는지, 어디서 직관과 현실이 어긋나는지를 본다. 이 봄이 학습이다.

활동지의 중심이 구조화형이면 학생의 사고는 활동지 위에서 시각화된다.

### 왜 탐구형이 마지막인가

탐구형이 활동지의 첫 자리에 오면 학생은 출발점을 찾지 못한다. 학생은 먼저 [수용]으로 개념을 만나고, [구조화]로 개념을 사용해 본 뒤, [탐구]에서 자기 자리로 옮겨간다.

탐구형은 활동지의 끝에 두어 학습이 종이 밖으로 나가는 다리가 되게 한다.

## 4단 구조와 세 층위의 만남

| 4단 단계 | 가장 자주 쓰이는 층위 | 비고 |
|---|---|---|
| **예상** | 탐구형 | 정답이 정해지지 않은 직감의 자리 |
| **확인** | 구조화형 | 단계별 사고로 실제 답에 도달 |
| **설명** | 구조화형 | 차이를 자기 언어로 정리 |
| **재해석** | 탐구형 | 자기 일상으로 일반화 |

수용형은 4단 구조의 어디에도 자연스럽게 자리 잡지 못한다. 그래서 수용형은 활동지의 본 흐름이 아니라 **별도의 사전 점검 문항**으로 따로 두는 경우가 많다.

```
[사전 점검] 0. 지수함수의 정의를 한 문장으로 적으시오. (수용형)

---

[예상] 1. ... (탐구형)
[확인] 2. ... (구조화형)
[설명] 3. ... (구조화형)
[재해석] 4. ... (탐구형)
```

이 경우 활동지의 본 흐름(1~4번)은 수용형 0%로 구성된다. 사전 점검의 한 문항만 수용형이다.

## 자가 진단 시 세 층위 분포 점검 방법

활동지를 작성한 뒤, 각 문항을 다음 기준으로 분류한다.

### 분류 흐름도

```
문항 텍스트를 본다.
│
├── 학생이 답을 본문이나 수업에서 그대로 가져오는가?
│   └── 예 → 수용형
│
├── 학생이 단계별로 풀어 나가지만 답은 정해져 있는가?
│   └── 예 → 구조화형
│
└── 학생마다 답이 다를 수 있는가?
    └── 예 → 탐구형
```

### 분포 기록 형식

자가 진단표의 2번 항목에 다음과 같이 기록한다.

```
2. 세 층위 분포 — ✓ 통과 / △ 확인 필요 / ✗ 미통과
   (수용형 N개 / 구조화형 N개 / 탐구형 N개)
```

### 통과 기준

- 수용형이 전체의 20%를 넘지 않는다 (5문항이면 1개 이내)
- 구조화형과 탐구형이 합쳐서 전체의 80% 이상이다
- 4단 구조의 각 단계에 적어도 하나의 문항이 들어 있다

이 세 가지 모두 만족하면 ✓ 통과다.

### 미통과의 흔한 패턴

- **수용형 과다**: 학생이 본문을 그대로 옮겨 적는 문항이 절반 이상 → 구조화형으로 재작성
- **구조화형 부재**: 정답을 그냥 묻고 끝난 문항만 있음 → 비교·차이 설명을 추가
- **탐구형 부재**: 마지막 문항이 단원 정리에 머무름 → "당신의 사례", "당신의 가치관"으로 확장
- **4단 단계 누락**: [예상] 또는 [재해석]이 통째로 빠짐 → 4단 구조 자체를 다시 검토
