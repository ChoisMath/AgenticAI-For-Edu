# 자료의 위험 신호 진단표

이 자료는 material-validator skill의 워크플로우 1단계에서 사용하는 빠른 스크리닝 도구다. 본격 점검(다섯 비평가 호출) 전에 자료를 훑어보고, 위험 가능성이 큰 항목을 우선 식별한다.

이 진단표의 목적은 점검의 정확도를 높이는 것이 아니라 **점검의 방향을 잡아 주는 것**이다. 신호가 발견되면 해당 비평가가 그 부분을 더 깊이 본다. 신호가 없는 영역은 통과로 빠르게 처리된다.

---

## 빠른 스크리닝 절차

자료를 받자마자 다음 다섯 영역을 순서대로 훑어본다. 각 영역의 위험 신호가 있으면 해당 비평가의 점검 우선순위가 높아진다.

### 영역 1. 사실 위험 신호 → 사실확인_비평가에게 우선

다음을 자료에서 찾는다.

| 신호 | 위험 강도 | 비평가의 행동 |
|---|---|---|
| 통계 수치 (퍼센트, 비율, 큰 숫자) | 높음 | 모든 통계를 [확인필요]로 일단 표시 |
| 연도 (사건, 인물 생몰년, 출간일) | 높음 | 연도와 사건의 일치 점검 |
| 외국 학자 이름·소속·직책 | 높음 | 인물의 실재성·직책 확인 권고 |
| 책·논문 제목 (특히 외국 출처) | 매우 높음 | 출처 실재성 확인 권고 (AI는 논문을 자주 지어냄) |
| 단원과 직접 관련된 핵심 수치 | 높음 | 외부 검증 필수 권고 |
| 한국 인물의 직책·소속 | 중간 | 현재 직책·소속 확인 권고 |
| 역사 인물의 생몰년·업적 | 중간 | 일반적 사실은 통과 가능 |

#### 자료에 신호가 없는 경우
- 추상적 개념 설명, 사고 유발 텍스트, 가상 인물의 사례 등은 사실 위험 신호가 적다.
- 이 경우 사실확인_비평가는 짧게 [통과]로 처리한다.

### 영역 2. 시의성 위험 신호 → 시의성_비평가에게 우선

다음을 자료에서 찾는다.

| 신호 | 위험 강도 |
|---|---|
| "최근", "현재", "오늘날", "요즘" | 높음 — 기준 시점 확인 필요 |
| 경제 지표 (GDP, 물가, 환율, 금리, 임금) | 매우 높음 — 매년 변함 |
| 인구 통계 (출산율, 사망률) | 매우 높음 — 분기별로 변함 |
| 기술 동향 (사용자 수, 점유율) | 높음 — 빠르게 변함 |
| 정치·사회 사실 (대통령, 정당 의석수) | 매우 높음 — 선거로 변함 |
| 법률 시행일·개정 | 높음 |
| 스포츠 기록·흥행 순위 | 중간 |

#### 신호가 없는 경우
- 수학 공식, 과학 법칙, 역사적 사실 등은 시의성 위험이 거의 없다.
- 이 경우 시의성_비평가는 짧게 [통과]로 처리한다.

### 영역 3. 편향 위험 신호 → 편향_비평가에게 우선

다음을 자료에서 찾는다.

| 신호 | 위험 강도 |
|---|---|
| 단정적 결론 ("그러므로 ~이다") | 높음 |
| 가치관 함축 표현 ("당연히", "물론", "누구나") | 중간 |
| 한쪽 관점만 자세히, 다른 쪽은 한 줄로 | 매우 높음 |
| 사례에서 한 인물이 다른 인물보다 호의적 묘사 | 매우 높음 |
| "X가 답이다", "X가 더 낫다" 식 결론 | 높음 |
| 사회·역사·환경 영역의 자료 | 중간 — 본질적으로 편향 위험 |

#### 영역별 흔한 편향
- 사회·역사: 한 진영의 관점에서 사건 서술
- 환경·과학: 위기 vs 회의론 한쪽 강조
- 경제: 한 가지 전략을 정답으로 제시
- 가족 묘사: 핵가족을 "정상"으로 전제
- 직업·성별·지역 고정관념

### 영역 4. 저작권 위험 신호 → 저작권_비평가에게 우선

다음을 자료에서 찾는다.

| 신호 | 위험 강도 |
|---|---|
| 큰따옴표 안의 인용문 (출처 없음) | 매우 높음 |
| 그래프, 차트, 도표, 이미지 | 높음 — 원 출처 확인 필요 |
| 통계 수치인데 출처 표기 없음 | 높음 |
| 한국어 문체가 갑자기 바뀌는 단락 | 매우 높음 — 외부 글 인용 가능성 |
| 시·소설·문학 작품의 일부 | 매우 높음 |
| 신문 기사·블로그 표현이 그대로 | 매우 높음 |

#### 외부 공유 가능성 점검
교사가 자료를 어떻게 사용할지에 따라 검증 강도가 달라진다.
- 교실 내 사용: 저작권법 제25조에 따라 폭이 넓음
- 동료 교사 배포: 폭이 좁아짐
- SNS·블로그 공개: 가장 엄격한 점검 필요

### 영역 5. 학생 적합성 위험 신호 → 학생적합성_비평가에게 우선

다음을 자료에서 찾는다.

| 신호 | 위험 강도 |
|---|---|
| 가족 형태 묘사 (부·모·자녀의 핵가족) | 높음 — 다양한 가족 학생 배제 위험 |
| 소득 수준 묘사 ("부자", "가난한") | 높음 — 가치 판단 위험 |
| 종교·성별 정체성·인종 언급 | 매우 높음 — 신중 검토 |
| 죽음·자살·폭력 등 무거운 주제 | 높음 — 처리 방식 점검 |
| 학년에 어려운 전문 용어 (풀어쓰지 않음) | 중간 — 학년 적합성 |
| 추상적 개념을 자명한 것처럼 다룸 | 중간 |

#### 학급 의존성
이 영역은 학급 구성에 따라 적절성이 달라진다. 비평가는 위험 신호를 알릴 뿐, 최종 판단은 교사의 학급 맥락 이해에 맡긴다.

## 빠른 스크리닝 결과의 출력 형식

본격 점검에 들어가기 전, 1단계의 결과를 다음과 같은 한 줄 요약으로 정리한다 (내부 작업용 — 최종 출력에는 포함하지 않음).

```
[1단계 빠른 스크리닝]
- 사실 위험: 강 / 중 / 약 (몇 개 항목 발견)
- 시의성 위험: 강 / 중 / 약
- 편향 위험: 강 / 중 / 약
- 저작권 위험: 강 / 중 / 약
- 학생 적합성 위험: 강 / 중 / 약
- 우선 점검 비평가: (위험이 가장 높은 영역의 비평가 1~2명)
```

이 결과에 따라 비평가별 점검 깊이가 결정된다.

- **위험 강** — 비평가가 자료를 단어 단위로 정밀 점검
- **위험 중** — 비평가가 의심 영역을 표시하고 외부 검증 권고
- **위험 약** — 비평가가 빠르게 [통과]로 처리

## 자료 유형별 위험 신호 패턴

자료가 어떤 skill로 만들어졌는지에 따라 위험 신호 패턴이 다르다. 이 정보가 입력에 있으면 점검의 정밀도가 올라간다.

### reading-material로 만든 자료

- 사실 위험: 매우 높음 (사고 유발용 사례에 통계·인물·연도 다수 등장)
- 시의성 위험: 중간
- 편향 위험: 중간 — 단정적 결론은 적지만 가치관 함축 표현 가능
- 저작권 위험: 높음 — 인용처럼 보이는 문장이 등장할 가능성
- 학생 적합성 위험: 중간 — 학년별 어휘 점검 필요

### activity-sheet로 만든 자료

- 사실 위험: 중간 (활동지의 과제 설정에 사용된 수치)
- 시의성 위험: 낮음
- 편향 위험: 낮음 — 학생 답을 적게 하는 구조라 단정적 결론 적음
- 저작권 위험: 낮음 — 활동지는 보통 자체 작성
- 학생 적합성 위험: 높음 — 학생이 직접 답을 적는 구조이므로 정서적 무게에 민감

### interactive-visualizer로 만든 자료

- 사실 위험: 매우 높음 (수학적·과학적 정확성)
- 시의성 위험: 낮음 — 수식·법칙 기반
- 편향 위험: 낮음
- 저작권 위험: 낮음 — 코드는 자체 생성
- 학생 적합성 위험: 중간 — 학년별 복잡성 점검 필요

### case-based-problem으로 만든 자료

- 사실 위험: 높음 (사례 속 통계, 인물의 직업·환경 사실성)
- 시의성 위험: 높음 (경제 사례라면 이율·이자율의 시점)
- 편향 위험: 매우 높음 — 갈림길의 균형 점검
- 저작권 위험: 중간
- 학생 적합성 위험: 매우 높음 — 인물의 가족·소득·정체성 묘사 점검

이 패턴은 점검의 시작점일 뿐, 절대 기준이 아니다. 자료의 실제 내용을 보고 위험 신호를 식별한다.

---

## 위험 신호가 전혀 없는 경우

자료를 훑어 위험 신호가 거의 발견되지 않으면, 다섯 비평가 모두 짧게 [통과]로 처리한다. 통합 결과는 "배포 가능"으로 나간다.

이 경우에도 다섯 비평가의 표는 모두 작성한다. 각 영역에 위험 신호가 없었음을 명시적으로 보여 주는 것이 점검의 형식이다.
