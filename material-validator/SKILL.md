# material-validator skill

학생에게 배포하기 전 자료를 다섯 가지 기준으로 점검한다.

## 핵심 원칙

이 skill은 다음 한 가지 전제 위에 만들어졌다.

> 매끈함과 신뢰성은 다르다.

AI가 만든 자료는 매끈하다. 그러나 매끈한 자료가 정확한 자료는 아니다. 매끈한 자료가 적절한 자료도 아니다. 매끈한 자료가 합법적인 자료도 아니다. 학생이 AI 자료의 단순한 수신자가 아니라 그 자료를 통해 세상을 보는 사람이라면, 자료는 한 번 더 점검을 거쳐야 한다.

이 점검의 책임은 AI에게 있지 않다. AI는 책임을 질 수 없는 도구다. 출판사에 있지도 않다. 출판사는 이 자료를 본 적이 없다. 결국 책임은 그 자료를 학생 앞에 놓는 사람, 곧 교사에게 있다. 교사는 AI 시대 자료의 마지막 게이트키퍼다.

다행히 점검은 길지 않다. 5분이면 된다.

## 핵심 메시지

> 이 skill의 결과는 점검의 끝이 아니라 점검의 시작이다.

AI가 자기 자신을 점검하는 일에는 한계가 있다. 자기가 만든 자료의 사실 오류를 자기가 발견하기는 어렵다. 그래서 material-validator는 자료를 [통과/확인필요/위험]으로 분류해 교사에게 건넨다. '확인필요' 항목은 교사가 외부 출처(웹 검색, 공식 사이트, 학술 자료)로 직접 확인해야 한다.

이 skill은 점검을 대신해 주는 것이 아니라, 교사가 무엇을 점검해야 하는지를 짚어 준다.

## 다른 skill들과의 결정적 차이

| 항목 | 다른 4개 skill | material-validator |
|---|---|---|
| **결과물** | 자료 생성 | 자료 검증 (생성 안 함) |
| **subagents 폴더** | 비평가 1명 | **비평가 5명** (각 점검 항목별) |
| **"비평가 모드 전환"** | 핵심 워크플로우 단계 | **없음 — skill 호출 자체가 5명 호출** |
| **자가 진단표** | 본문 직후 출력 | **없음 — 5명 비평가 통합 표가 결과** |
| **호출 시점** | 단원 진행 중 | **자료 배포 직전 (마지막 게이트)** |

특히 "비평가 모드 전환이 없다"는 점이 워크플로우의 본질을 바꾼다. 이 skill을 호출하는 것이 곧 다섯 비평가 모두를 호출하는 일이다.

## 입력

교사로부터 다음을 받는다.

- **자료 본문**: 점검할 자료 전체 (읽기 자료·활동지·사례·시각 자료의 텍스트 부분 등)
- **(선택) 자료 유형**: reading-material / activity-sheet / interactive-visualizer / case-based-problem 중 어느 skill로 만들었는지
- **(선택) 학년·교과**: 학생 적합성 점검에 필요
- **(선택) 핵심 수치 목록**: 자료 안에서 특별히 의심되는 수치가 있다면 명시

자료 본문이 없으면 작업을 시작하지 않는다. 자료 유형, 학년·교과, 핵심 수치 목록은 없어도 작업 가능하지만, 있으면 점검의 정밀도가 올라간다.

## 워크플로우

### 1단계. 위험 신호 진단

`resources/위험_신호_진단표.md`를 읽어 자료 전체를 빠르게 훑어보고, 위험 가능성이 큰 항목을 우선 식별한다.

위험 신호 예:
- 통계 수치, 연도, 인물 이름, 책 제목, 논문 출처 (사실 오류 빈발 영역)
- "최근", "현재", "오늘날" 같은 시점 표현 (시의성 의심)
- 한쪽 가치관에 기운 표현, 단정적 결론 (편향 의심)
- 외부 인용처럼 보이는 문장, 그래프·도표 (저작권 의심)
- 가족·소득·종교·정체성 관련 묘사 (학생 적합성 의심)

이 1단계는 본격 점검 전의 빠른 스크리닝이다.

### 2단계. 5명 비평가 차례로 호출

각 비평가는 자기 항목만 깊이 본다. 한 비평가가 다섯 항목을 동시에 보면 어느 항목도 깊이 가지 못하기 때문이다.

| 비평가 | 점검 영역 | 참조 파일 |
|---|---|---|
| **사실확인_비평가** | 수치, 인용, 인물, 사건의 정확성 | subagents/사실확인_비평가.md |
| **시의성_비평가** | 시간이 지나면 변하는 데이터의 갱신 | subagents/시의성_비평가.md |
| **편향_비평가** | 한 관점만 강조되어 있는지 | subagents/편향_비평가.md |
| **저작권_비평가** | 출처 미표기, 인용 범위 초과 | subagents/저작권_비평가.md |
| **학생적합성_비평가** | 어휘·정서·맥락의 적합성 | subagents/학생적합성_비평가.md |

각 비평가의 자세, 점검 기준, 출력 형식은 해당 파일에 정의되어 있다. 비평가별 응답을 모두 받은 뒤 3단계로 넘어간다.

### 3단계. 통합 결과 정리

다섯 비평가의 응답을 다음 형식으로 통합한다.

```
[material-validator 점검 결과]

점검 대상: (자료 제목)
점검 일자: (오늘 날짜)

[1. 사실확인_비평가]
    - 항목 N: [통과/확인필요/위험] — 한 줄 근거
    - 항목 N: [통과/확인필요/위험] — 한 줄 근거
    - ...

[2. 시의성_비평가]
    - (동일 형식)

[3. 편향_비평가]
    - (동일 형식)

[4. 저작권_비평가]
    - (동일 형식)

[5. 학생적합성_비평가]
    - (동일 형식)

[종합]
- 통과: N개 / 확인필요: N개 / 위험: N개
- 우선 확인 필요 항목: (가장 중요한 1~3개)
- 종합 판단: "배포 가능" / "확인 후 배포" / "수정 후 재점검"
```

### 4단계. 교사에게 안내

'확인 필요'와 '위험' 항목 중 핵심 사실에 대해서는 교사가 외부 출처로 직접 확인해야 함을 명시적으로 안내한다.

> "다음 N개 항목은 외부 출처로 직접 확인이 필요합니다. 웹 검색이나 공식 사이트(NASA, KOSIS, 한국은행 등)를 통해 확인해 주세요. 확인 후 자료를 수정하거나 그대로 사용할지 결정합니다."

이 단계의 핵심은 **AI가 자기 점검의 한계를 솔직히 인정**하는 것이다. material-validator가 잡아낸 것을 교사에게 그대로 떠넘기는 것이 아니라, 교사가 무엇에 집중해 외부 검증을 해야 하는지를 짚어 준다.

## 출력 형식 (정식 템플릿)

```markdown
# [material-validator 점검 결과]

**점검 대상**: (자료 제목 또는 첫 한 줄)
**자료 유형**: (제공된 경우)
**점검 일자**: (오늘)

---

## 1. 사실확인_비평가

| 항목 | 판정 | 근거 |
|---|---|---|
| (수치·인용·인물·사건별로 한 줄씩) | 통과/확인필요/위험 | 한 줄 |

## 2. 시의성_비평가

| 항목 | 판정 | 근거 |
|---|---|---|

## 3. 편향_비평가

| 항목 | 판정 | 근거 |
|---|---|---|

## 4. 저작권_비평가

| 항목 | 판정 | 근거 |
|---|---|---|

## 5. 학생적합성_비평가

| 항목 | 판정 | 근거 |
|---|---|---|

---

## [종합]

- **점검 항목 총 N개**: 통과 N / 확인필요 N / 위험 N
- **우선 확인 필요** (가장 중요한 1~3개):
  1. ...
  2. ...
  3. ...
- **종합 판단**: 배포 가능 / 확인 후 배포 / 수정 후 재점검
- **권고**: (한 단락으로 다음 행동 안내)

> 이 결과는 점검의 시작입니다. '확인필요'·'위험' 항목은
> 외부 출처로 직접 검증한 뒤 자료를 학생 앞에 놓아 주세요.
```

## 회피 사항

이 skill은 다음을 하지 않는다.

- 자료를 새로 생성 (reading-material·activity-sheet·interactive-visualizer·case-based-problem skill의 영역)
- 자료를 자동으로 수정 — 점검 결과를 알릴 뿐, 수정은 교사가 결정
- "이 자료가 옳다/그르다"는 단정적 판단 — 모든 의심 항목은 [확인필요]로 표시하고 외부 검증을 권고
- 외부 사실의 자체 검증 — 웹 검색이 가능한 환경에서도 AI가 자기 검증을 신뢰하지 않고 교사에게 외부 검증을 안내

이 skill은 오직 "자료의 위험 신호를 다섯 각도에서 식별하고 교사에게 짚어 주는 일"만 한다.

## 종합 판단의 기준

| 위험 | 확인필요 | 종합 판단 |
|---|---|---|
| 0개 | 0개 | 배포 가능 (즉시 학생 사용 가능) |
| 0개 | 1~3개 | 확인 후 배포 (해당 항목만 외부 검증 후 수정 또는 그대로 사용) |
| 0개 | 4개 이상 | 확인 후 배포 — 다만 검증 시간이 5분을 넘을 가능성 있음 |
| 1~2개 | (무관) | 수정 후 재점검 (위험 항목은 반드시 수정 또는 제거) |
| 3개 이상 | (무관) | 수정 후 재점검 — 자료의 신뢰성에 광범위한 의심 |

## 작성 예시 (참고)

다음은 한 호출의 입력과 출력 골격이다.

**입력**: 5-1에서 만든 '종이접기' 읽기 자료의 본문 + 핵심 수치 목록 (0.1mm, 10번 접기 10.2cm, 20번 105m, 30번 107km, 42번 44만km, 지구–달 거리 38만km)

**출력의 골격**:

```
# [material-validator 점검 결과]

점검 대상: '종이를 몇 번 접으면 어디까지 닿을까' 읽기 자료

## 1. 사실확인_비평가

| 항목 | 판정 | 근거 |
|---|---|---|
| 종이 두께 0.1mm | 통과 | 일반 복사용지 평균 |
| 10번 접기 10.2cm | 통과 | 2¹⁰ × 0.1mm = 102.4mm 일치 |
| 20번 접기 105m | 통과 | 2²⁰ × 0.1mm 일치 (104.86m, 반올림) |
| 30번 접기 107km | 통과 | 2³⁰ × 0.1mm 일치 (107.4km) |
| 42번 접기 44만km | 통과 | 2⁴² × 0.1mm 일치 (439,804km) |
| 지구–달 거리 38만km | 확인필요 | NASA 공식 평균 384,400km. 본문은 반올림 표기. 학생용으로 적절하나 정밀도 원할 시 갱신 가능 |

## 2. 시의성_비평가

| 항목 | 판정 | 근거 |
|---|---|---|
| 시의성 의존 정보 | 통과 | 시간 변동 정보 없음 |

(이하 동일 형식)

## [종합]
- 점검 항목 총 N개: 통과 N / 확인필요 1 / 위험 0
- 우선 확인 필요: 지구-달 거리 (NASA 공식)
- 종합 판단: 확인 후 배포
```

이 골격은 강제 형식이 아니다. 자료 종류와 길이에 따라 점검 항목 수가 달라진다. 다만 다섯 비평가별 표 + 통합 종합 구조는 항상 유지된다.
